# 建筑、地层与探索地图 · 2026-09-16

## 用户要求与本轮实现

建筑和地形不能继续停留在平板占位表现；新增 M 键，查看当前场景地图与世界地图，未到访部分用黑幕覆盖。

- 建筑：以现有小人物尺度绘制四种侧视建筑。仓屋使用旧木板，旅舍使用灰泥填充和交叉屋架，工坊使用较大的框架与窗，隐士住处使用较低的苔覆屋顶。加入石基础、木梁接缝、搭接瓦片、屋檐阴影、凹陷门窗、窗板、门槛、烟囱和少量生活物件。
- 土岩层：取消续篇地面的固定 22 px 土层分界，改为不规则土壤厚度、根系、局部潮湿色与岩层嵌入。岩体使用较安静的块面、断续裂隙和少量细矿物，不用整面高亮碎点覆盖岩石。深部适度压暗，行走表面仍与现有碰撞一致。
- 这些是原生像素代码绘制，没有新增 AI 位图，也没有导入 Noita 贴图。人物 v0.6、远景 v0.3、步态和相机参数不变。房屋仍是背景建筑，不借本轮美术变更承诺新增可进入室内或屋顶攀爬。
- M / Esc 打开、关闭地图；右侧小地图按钮支持鼠标与触摸。当前场景地图支持拖动、滚轮/按钮缩放、回到当前位置。打开地图暂停模拟并清空持续输入，不会边读地图边走入危险区域。
- 黑幕以 16 px 地图格记录，人物附近固定约 160×96 px 半径内探索；与屏幕、相机和地图缩放无关。采样现有实际地形，射线遇实体后不揭开后方地图格。仅显示已经探到的地标，地图没有传送或写任务标志的接口。
- 世界图展示已实现森林地点间的连接；未到访地点保持未知，平原方向明确标为后续未开放。它是区域连接示意，不是新确定的大陆地理。尚未开发的地下位点和其他世界内容不虚构成可进入地图。

## 存档与性能边界

探索单独保存到 `tokipona.forest-cartography.v0.1`，不改动原开场、续篇、MP、钱包、学习或任务存档。临时重玩使用同一 practice 后缀的 sessionStorage，与主进度隔离。旧档不会清空；此前没有地图轨迹，故从本次更新后的当前位置开始记录，不伪造历史探索范围。

只保存已探索的格子及当时所见材质；范围、材质编号和索引顺序均验证。损坏地图字节保留，不阻塞游戏，只在内存暂存新探索，并提示可导出原数据。存储满时提示重试/备份。地图记录不是剧情权威，不因地图失败回滚玩家任务。

地图在人物移动或定期低频更新时采样，材质更新不读取整张大世界；建筑和木梁先绘制到缓存，普通帧复用。新模块延迟载入，保留原构建大小及请求预算。
