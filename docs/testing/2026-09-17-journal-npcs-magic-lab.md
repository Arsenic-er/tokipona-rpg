## 实验室入口与隔离

- 暂停菜单 →「独立魔法实验室（不改主进度）」。浏览器独立入口为 `magic-lab.html`，桌面版通过同一 EXE 的本地页面进入，不需要第二份 EXE 或服务器。
- 实验室模型没有存档、任务、学习账本或主线权限写入接口。离开／重置清除本次试验，不清空主游戏。返回临时旅程时只保留经过验证的 32 位 practice 槽位参数，不接受任意跳转网址。
- 桌面本地页面白名单仅新增 `/magic-lab.html`；沙箱、关闭 Node 集成、禁外网、禁止任意文件访问均保留。
- 独立实验 MP 上限 100，默认无限，可关闭无限并手动补满。没有给主线发放能力、金钱、攻击许可或学习记录。

## 当前可试范围

工作台有可编辑表达、逐词加入、17 个示例、MP 报价与效果说明。支持六个基础词 `telo / seli / lete / kiwen / ko / kon`；五种可延展元素可用 `suli / lili`，保持固定截面和既有 1/2/4 格轴向长度，不把长短解释为强弱。

| 试验 | 可见物理结果 | 边界 |
|---|---|---|
| telo / telo suli / telo lili | 显化水，随后流动、下落 | 复用既有 Telo CastPlan 的几何和费用；预览／落格同源 |
| seli / lete | 木料燃烧、水冻结、冰融化 | 30 Hz 材料核心真实变化；不是只换颜色 |
| telo lete / telo seli | 冷水和热水的相变试验 | 实验组合，不作为主线语言审阅结论 |
| telo kon / ko kon | 3 秒局部扰动抬升水／沙，结束后下落 | 固定时长、预付实验费用；不是无限悬停 |
| telo o tawa | 低速水流，碰撞释放为材料水 | 不具备冲击破坏力 |
| telo kon o tawa | 凝聚水团沿瞄准方向移动，碰撞／到时散开 | 原型效果，尚非正式攻击签名 |
| telo o tawa wawa | 有力水流冲击削弱土岩／木料，留下实际缺口 | 18 实验 MP，冲击标定独立于主线伤害、资格与证据账本 |
| kiwen / ko | 固定硬质构形／会堆积下落的沙土 | 硬质构形整块坠落暂未接入，不声称完整刚体模拟 |

未实现组合明确拒绝且不扣 MP，不把「尚未实现」判为道本语语法错误。重复填词不会偷偷降成已支持的单词法术。最多同时 20 个持续场／水团，超过时明确拒绝。

场地为 768×384 世界像素，2 px 材料格。左侧土岩床、木样和水沙槽可改变；右侧与外框的蓝灰色结构由独立锁定掩码保护。显化不能替换实体，碰到边界／锁定结构的实体构形拒绝而不静默缩短。热冷／力场遇锁定结构遮挡，水流冲击不会摧毁锁定结构。撞墙释放水的采样也做实体视线检查，防止薄墙背面凭空出现水。同日根据沙埋自救反馈，已撤销对自身范围的一刀切限制：热、冷、气流、水和冲击可覆盖自身，仅禁止沙石直接生成在身体内；详见 [近身施法修订](2026-09-17-lab-self-cast.md)。

鼠标瞄准、左键单次施法；A/D、空格使用原人物运动内核。触屏先点场地瞄准，再用独立施法按钮，避免拖动时连续误施法。键入表达不会移动人物；失焦清输入并暂停。提供暂停、回安全台、补 MP、确认后重置。实验室没有战斗敌人、玩家受伤、完整压力流体或全语言自由编译器。
