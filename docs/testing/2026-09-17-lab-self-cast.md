# 实验室近身施法与沙埋自救 · 2026-09-17

## 用户反馈与范围

用户指出：魔法应能覆盖玩家自身范围，否则被沙子埋住时无法施法自救。本轮只修订独立实验室的施法边界，主游戏的法术权限、剧情、存档、玩家运动与步态不变。

## 原因与修订

- 旧实现把所有非投射法术都套进“构形不得碰到身体”的拒绝条件，误伤热、冷、气流。现在这些场可以覆盖玩家，水也可以包围／浸没玩家；仍禁止在身体内直接生成沙、石实体，显化仍不能替换已有材料。
- 旧水流的起发点在身体外侧，紧邻沙土时被判阻塞，又要求退开才能施法。现在从身体中心起发并连续扫掠地形；碰到紧贴身体的材料即发生碰撞。有力水流可破开可破坏材料，低速水流不获得额外破坏能力。
- 发射点已被固体占据时，先处理当前格碰撞，不把水团移出固体再飞行。正好瞄准自身中心也可以施法，以面朝方向作为零距离方向，避免 NaN。
- 不可破坏掩码及冲击／溅水遮挡继续有效。新增贴身锁定薄墙测试，确保改起点不会让水流出现在墙后。
- UI 操作说明加入自救方法，并注明实验室暂未结算玩家受伤，不能据此承诺正式游戏对自己施法免伤。没有增加新法术词义、费用或主线攻击资格。

## 验证范围

模型测试构建玩家被沙堆包围、留有身体空腔的状态：先确认右移无效；有限 100 MP 下 5 次 `telo o tawa wawa` 消耗 90 MP，再通过正常右移和跳跃离开原沙堆范围。没有使用“回安全台”、重置、传送或修改人物坐标完成逃脱。首次只保持右移的测试未越过残留沙唇，补入正常跳跃操作后通过，未为了测试改动移动或伤害参数。

另测自身体积内热／冷／气流／水预览与执行、沙石拒绝与 MP 不变、发射点被埋、零距离方向、低速水流无破坏力、贴身不可破坏墙与原薄墙溅水隔离。浏览器与 EXE 测试使用普通指针／键盘对自身施放气流和近身水流；实际沙堆逃脱的完整过程由模型测试覆盖，不混称全部已原生操作验证。
