# 第一章森林开场切片验收

## 试玩入口

运行 `pnpm dev` 后打开 `http://127.0.0.1:5173/chapter-one.html`。

这是第一章开场的正式最小切片：旅者从黎明森林抵达受损溪路，选择一种办法通过，观察一处未知刻痕，然后抵达林间聚落边缘。`world-scale.html` 仍是世界尺度与碰撞灰盒，不代表正式试玩画面。

当前公开仓没有通过审批的森林运行时素材包。页面会明确显示“候选视觉 · 尚未通过素材审批”，并使用程序化候选画面安全降级；这不等于最终美术验收。私有候选素材不会被公开构建读取。

## 操作

- 键盘：`A/D` 或左右方向键移动，`W`、上方向键或空格跳跃，`E` 互动，`F` 观察，`Esc` 暂停。
- 横屏触控：左侧方向键移动；右侧“用”“看”“↑”分别对应互动、观察和跳跃。
- 暂停菜单：“返回检查点”只回退物理位置和未提交局部状态，已经提交的过溪解法不会丢失。
- 右上角“声音：开/关”是独立持久设置；`Esc` 无论焦点在画布还是暂停菜单按钮上都能同步暂停/继续。

一条路线通常需要 1–3 分钟。完整浏览器自动验收包含三种过溪解法、桌面和横屏触控、页面关闭后恢复、坏档恢复与检查点回退，约需 3–5 分钟，取决于机器性能。

## 可验收内容

1. 游戏画布覆盖 1440×900 桌面与 844×390 横屏视口，旅者在整段路线中保持可见。
2. 三条互斥路线都能完成同一个语义目标：推动两块松石、拖动枯木、涉水绕行。
3. 兔子会逃入遮蔽物，湿地鸟会起飞离开；它们不会阻塞主路线。
4. 未知刻痕只记录“看见过 `telo` 图形”，不会授予词义、发音、学习证据、法术或 MP。
5. 抵达聚落时保持零击杀；关闭页面再进入，结果不重复提交。
6. 坏档保持原字节，不自动新建覆盖；玩家可先导出，再明确重置。

## 自动门禁

在 Node 22 环境运行：

```powershell
pnpm run test:forest-opening
```

该命令依次运行森林开场内容/运行时/协调器/存档/视图/音频单测、生产构建、公开素材边界检查和浏览器验收。素材尚未获批时，`assets:check` 应以 `safe_blocked_pending_external_approval` 安全通过边界检查；它不会把候选素材当成已发布素材。

若要单独查看浏览器证据：

```powershell
pnpm run build
pnpm exec playwright test e2e/forest-opening-slice.spec.ts
```

成功运行会在 Playwright 输出目录保留候选阶段的桌面/移动端黎明、障碍与聚落截图；失败时另保留截图、trace 和视频。获批素材一旦缺文件、尺寸错误或清单不合规，正式入口会明确显示“获批素材加载失败”，不会冒充候选待审或悄悄宣布已获批。最终视觉仍需用户审核私有素材候选并完成许可、可访问性与发布审批后才能签字。

需要保留一次无旁白完整试玩视频时，可在 PowerShell 中运行：

```powershell
$env:FOREST_OPENING_CAPTURE_VIDEO = "1"
pnpm exec playwright test e2e/forest-opening-slice.spec.ts -g "mobile complete route"
Remove-Item Env:FOREST_OPENING_CAPTURE_VIDEO
```
