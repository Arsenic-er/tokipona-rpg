## 2. 明确未完成的内容

- 当前画面仍以 `180×320`、`270×480`、`360×640` 三个纵向审计视口为原型，不是用户要求的响应式真全屏横版镜头。
- 原型只接通 N00/N01 的有限移动与语言交互，没有接通十个正式场景的完整出口、任务门槛和回访路线。
- 当前人物是临时偏宽占位模型，尚未实现未来的玩家外观/起源/种族自定义。
- 玩家光源和部分 VFX 仍是审计期占位效果；用户已要求正式人物不带常驻发光。
- 环境生成主要验证 N00 干燥崖台与 N01 潮湿溪谷，尚未按所有场景的地形、气候、生态和文明层分别生成。
- 视觉原型尚未合并到 `main`；保存本分支是为了服务器到期后能继续审计，而不是宣告阶段完成。

## 6. 数据恢复原则

- Git 分支是代码、计划、日志和可公开资源的恢复源。
- 私有素材仓是源字体、评审候选、许可与审核记录的唯一恢复源。
- 本地 Vite 服务、构建目录、依赖缓存、临时脚本和 `.codex-tmp` 不属于需要备份的权威数据。
- 未经审核的二进制素材不得为了“备份方便”复制进公开仓。
