# 森林第一章《水往何处》设计规格

- 状态：用户已批准的叙事设计 v0.1；内容权威已实现
- 日期：2026-08-28
- 目标平台顺序：Windows 垂直切片优先，Android 后续适配
- 决策来源：[Q1–Q178 决策日志](../../design/world/00-worldbuilding-decision-log-zh.md)与[一致性审计](../../design/world/02-worldbuilding-consistency-audit-zh.md)

本状态仅表示章节、地点、生态、课程和验收内容契约及其严格运行时内容投影已经实现并由集成门锁定；不表示可玩运行时已经完成。运行时 reducer／Flow、保存与重放接线、正式 UI、美术资产和端到端验收保持开放，待后续运行时实施计划落地。

## 1. 设计目标

森林第一章以未知身份的人类旅行者为默认主角，在约三小时首次主线中完成以下体验：

1. 先用身体、工具和环境规律进入山谷社会，不在开场提前施法；
2. 通过公共设施劳动获得暂住资格，并发现受损媒介本体与第一块破损位点碎片；
3. 向隐士学习安全使用方法和有限世界观，而不是从 UI 自动获得知识；
4. 依次在实际问题中接触 `telo`、`tawa`、`lili/suli` 与 `wawa`；
5. 经历“维修成功反而转移代价”的大型生物迁徙危机；
6. 在地下秩序节点发现旧改道记录，完成第一次不能完美满足三方的水流分配；
7. 得知其他古代位点与媒介碎片存在，获得离开森林继续调查的长期动机。

第一章主线必须支持零击杀完成。战斗、训练场、狩猎、加工、深层声望和角色支线均可丰富体验，但不能成为三小时主线的填充物或硬门槛。

## 2. 章节主题与叙事主轴

章节主题是：**修复不是抹去代价，而是在现实条件下重新分配代价。**

主轴采用已经批准的“劳动—成功—反噬—调查—选择”结构：

```text
外来者为生计接受公共设施工作
→ 工程成功并获得聚落初步信任
→ 水位变化暴露受损媒介与位点碎片
→ 隐士教会安全起步，并警告古代系统不是答案机器
→ 继续恢复供水，却迫使大型生物与幼体迁徙
→ 追查出聚落过去隐瞒的紧急改道
→ 进入地下秩序节点，面对受损系统的有限容量
→ 在聚落、湿地、旧路贸易之间作出临时优先分配
→ 第一块碎片记录选择，并显示其他失联位点的模糊方向
```

玩家不是拯救“无能居民”的天选英雄。聚落居民掌握劳动、历史和生存经验；主角的特殊之处是能与受损媒介建立异常兼容，并愿意进入各方都无法单独处理的旧系统。

## 3. 三小时节拍

`180` 分钟是首次主线路径的目标中位数，不是倒计时。统计排除暂停、设置、挂机和自由支线；正常首次游玩允许落在 `150–240` 分钟。

| 内容预算 | 地点与剧情 | 主要玩法 | 语言与媒介 |
|---:|---|---|---|
| 0–12 分 | 到达山脊：主角在异常后醒来 | 移动、跳跃、攀爬、拾取工具、观察异常 | 不施法，不拥有可用媒介 |
| 12–30 分 | 溪流旧路：处理道路障碍，遇到设施劳动者 | 浅水、软土、朽木、工具与绕行 | 只看见遗迹词形，不教学 |
| 30–55 分 | 边境聚落：取得暂住资格，接受公共设施工作 | 对话、聚落探索、交易基础、三方利益初次露面 | 建立“语言曾服务于设施”的认识 |
| 55–75 分 | 水轮峡谷：先用工具维修，改变水位 | 水流物理、多路线维修、第一次持久环境变化 | 暴露维护室，取得媒介本体和破损碎片 |
| 75–95 分 | 隐士居所：验证媒介和碎片 | 观察、预测、低风险实践、短对话 | 安全学习 `telo`；理解语言、MP、媒介与自然规律的分工 |
| 95–120 分 | 高位蓄水池：追查碎片指向的异常水路 | 平台移动、阀门、虹吸与长度机关 | 引入 `tawa`，再成对引入 `lili/suli` |
| 120–148 分 | 回流湿地：大型生物迁徙危机 | 追踪、观察、引导、安抚、阻隔、绕行或战斗 | 从无生命回流机关理解 `wawa`；伤害动物不产生语言证据 |
| 148–173 分 | 地下秩序节点：双段高潮第二段 | 异常物理、工具与魔法组合、历史调查 | 五词首次综合迁移；碎片完成第一次位点同步 |
| 173–180 分 | 返回聚落：临时水流分配与尾声 | 后果选择、人物反应、世界状态提交 | 节点显示其他失联位点的模糊方向 |

### 3.1 主玩法时间预算

活跃时间按一个主要类别统计，目标总和为 `180` 分钟：

| 主要玩法 | 目标分钟 | 占比 |
|---|---:|---:|
| 探索、平台移动与路线判断 | 35 | 19% |
| 工具、材料与设施机关 | 40 | 22% |
| 人物对话、社会观察与调查 | 35 | 19% |
| 道本语观察、预测、练习与实际施法 | 30 | 17% |
| 大型生物与生态处理 | 25 | 14% |
| 地下高潮、分配选择与尾声 | 15 | 9% |

### 3.2 可选内容预算

以下内容不计入三小时主线完成时间：

- 巢穴洞窟：`15–25` 分钟；
- 安全训练场：`15–25` 分钟；
- 居民委托、声望、深入调查、狩猎与加工：`30–90` 分钟；
- 第一章自然总游玩量约为 `3–5` 小时，但不设全收集时长发布门。

## 4. 7+2 地点结构

设计层使用 `M1–M7` 表示七张主线地点地图，避免在迁移完成前错误复用旧机器节点编号。

| 设计槽位 | 地点 | 章节职责 | 当前内容迁移 |
|---|---|---|---|
| M1 | 到达山脊 | 身体操作、异常醒来、工具取得 | 继承 `valley.arrival_shelf` |
| M2 | 溪流旧路 | 材料路线、遇见劳动者、隐士居所入口 | 继承 `valley.stream_section`，隐士居所作为内部子地点 |
| M3 | 边境聚落 | 社会中心、公共工作、分配选择与回访 | 继承 `valley.settlement` |
| M4 | 水轮峡谷 | 首次设施工作、维护室、媒介发现 | 继承 `valley.waterwheel`；将旧 `service_channel` 合并为下层维修子区，不再独立计图 |
| M5 | 高位蓄水池 | 运动、长度、虹吸与上游因果 | 继承 `valley.high_cistern` |
| M6 | 回流湿地 | 大型生物危机、生态调查、`wawa` 机关 | 扩展 `valley.return_channel` |
| M7 | 地下秩序节点 | 历史真相、异常物理、首次位点同步与高潮 | 新增正式地点；不得用 `old_mine_threshold` 代替 |
| O1 | 巢穴洞窟 | 可选生态、幼体与迁徙证据 | 改造 `valley.den_bypass` |
| O2 | 安全训练场 | 可选受控攻击资格 | 继承 `valley.safe_range` |

`valley.old_mine_threshold` 只作为第一章结束后通往下一大地区的边界，不计入森林第一章七张主线地图。

## 5. 五幕剧情

### 5.1 第一幕：陌生人

主角在山谷边缘醒来，只保留旅行者身份和零散记忆。环境存在一次可观察但无法解释的规则异常。玩家沿溪流旧路帮助设施劳动者处理障碍，以劳动而非预言获得进入聚落的机会。

聚落允许主角用公共工作换取食宿。居民不把主角视为救世主，也不立刻共享敏感历史。

### 5.2 第二幕：一次成功的修复

水轮维修必须先有完整工具路线。玩家改变水位后，封闭维护室暴露，取得受损媒介本体和与其熔接的破损位点碎片。

媒介只能发出微弱反应、残缺图形和安全警告，不自动开放施法。聚落灯光、工坊或公共水井恢复，形成刻意的短暂胜利。

### 5.3 第三幕：修复带来的代价

主角经隐士指导完成安全起步，再去高位蓄水池追查碎片响应。上游重新接通后，聚落供水改善，但回流湿地水位与迁徙路线改变。

大型半水生生物为了幼体、食物或水域接近聚落。它可能破坏田埂、储水结构和道路，但不是主动猎杀居民的恶兽。玩家处理危机后确认：大型生物是水流决策的受影响者，不是根因。

### 5.4 第四幕：被隐藏的旧账

地下节点记录两层历史：古代系统曾在聚落、湿地和旧路之间动态分配水量；上一次严重旱灾中，部分居民和议事成员秘密改道，救下聚落，却把代价转移给湿地与下游，并为避免追责和外部索赔隐藏记录。

受损节点和媒介无法立即恢复完美平衡。节点短暂认可主角的异常兼容，但不得确认王族血缘、失忆真相或敌对意识的完整身份。

### 5.5 第五幕：水往何处

玩家选择一个临时优先方案：

| 方案 | 立即收益 | 立即代价 | 后续修复方向 |
|---|---|---|---|
| 聚落优先 | 饮水和农作稳定，居民生活压力最低 | 湿地继续退化，大型生物迁徙压力增加 | 扩建回流渠、降低农田漏损 |
| 湿地优先 | 湿地与大型生物恢复，生态风险降低 | 聚落限水，部分食物和服务涨价 | 修蓄水槽、建立轮供制度 |
| 旧路贸易优先 | 药品、盐、金属和外部消息恢复 | 聚落与湿地都只能获得最低水量 | 修道路蓄水点、谈判外部补给 |

三种方案都必须能继续游戏，也都不能立即让三方满意。后续可通过工程、贸易、声望和新位点知识逐步接近平衡升级。

## 6. 媒介、碎片与隐士

### 6.1 三个不同概念

- **受损媒介本体**：承载、限制和显示施术结构的古代装置；第一章永久取得，不能出售、丢弃或被普通失败回滚；
- **媒介碎片**：与某个古代位点关联的权限、记录和局部结构模块；能扩展媒介，但不授予语言理解；
- **古代位点**：散布在不同大地区、维护局部自然关系的基础设施节点；每个位点拥有自己的社会历史、环境问题和碎片。

第一章发现的是媒介本体和第一块森林位点碎片。地下节点同步后，碎片成为首个已激活模块，并显示其他失联位点的大致方向。

### 6.2 隐士的进入路线

玩家可以通过三条叙事路线找到同一名隐士：

1. 向设施劳动者披露媒介，由劳动者介绍；
2. 隐瞒媒介，跟随碎片对旧标记的反应；
3. 向外来商旅询问，获得隐士居所线索。

路线改变哪些人物知道主角持有媒介，但不允许永久错过主线。

### 6.3 隐士教学

隐士通过一段短实践教授：

1. 观察自然水沿容器和坡度移动；
2. 识别碎片中反复出现的 `telo`；
3. 预测媒介启动后的出现位置和路径；
4. 用少量 MP 完成第一次受控表达；
5. 再用工具将结果稳定下来。

隐士明确解释语言、MP、媒介和自然规律的分工，但只知道多个位点存在、当前碎片指向附近地下节点，以及恢复旧网络可能唤醒危险系统。隐士不知道或拒绝确认主角身份、王族血缘、敌对意识来源和全部位点位置。

隐士是可靠的实践导师，不是全知旁白。其种族与文化名称留给后续种族规格决定，不影响第一章角色功能。

## 7. 核心人物负载

聚落保留 `7–9` 名可持续角色，但主线重点塑造四人：

| 角色功能 | 当前诉求 | 不能被写成 |
|---|---|---|
| 设施劳动者 | 修复供水、保护同事、承认现实限制 | 只负责派任务的标记 |
| 供水代表 | 保障饮水、农作和公共卫生 | 自私或无知的保守派 |
| 湿地照料者 | 保护迁徙路线、湿地与大型生物 | 永远正确的自然代言人 |
| 商路代表 | 保住药品、盐、金属与外部联系 | 单纯贪婪的商人 |

隐士是第五名主线角色。医者／旅店经营者、年轻学徒和外来商旅承担生活、恢复、媒介披露和外部世界视角，但三小时内不并行展开完整个人剧情。

## 8. 大型生物事件

大型生物是具有持续身份的半水生筑巢动物，存在幼体、食物、水域、迁徙和警告需求。正式物种名称由生态与美术规格共同决定。

主线接受以下处理方式：

- 修复或临时打开迁徙水道；
- 用食物、气味或环境声音引导；
- 观察警告后退让，等待其移动；
- 设置非致命阻隔；
- 用已理解的低强度表达安抚或改变环境；
- 战斗驱离或击杀。

击杀可以继续主线，但会改变尸体、幼体、湿地、居民判断与后续生态；不得掉落主线钥匙、语言证据或高额唯一奖励。大型生物死亡后不能通过离屏刷新复活。

## 9. 五词学习路径

| 词 | 首次主动情境 | 第二情境 | 第一章目标 |
|---|---|---|---|
| `telo` | 隐士的水容器实践 | 水轮／蓄水池实际供水 | 能预测水出现和流动结果 |
| `tawa` | 蓄水池移动流体或小物件 | 地下节点改变运动关系 | 理解运动而非“位移技能” |
| `lili` | 蓄水池短结构／小尺度对照 | 地下节点限制规模 | 与 `suli` 形成可比较概念 |
| `suli` | 蓄水池长结构／大尺度对照 | 地下节点扩大作用范围 | 理解规模增加也增加负荷 |
| `wawa` | 回流湿地的无生命机关 | 地下节点控制能量输入 | 理解力量／能量，不从伤害动物学习 |

工具路线可以完成主线世界目标，但不得伪造语言理解。语言路线也不能绕过材料、能量、MP 和安全约束。中文释义与学习日志始终可查；错误组合给出稳定、可解释的有限结果或拒绝，不使用随机致死作为教学。

## 10. 失败、恢复与持久化

- 普通常规失败表现为战败或失能，由有来源的救援、撤离或拘留返回安全点；
- 任一主线路段至少有一条不依赖魔法、不依赖击杀的工具或环境路线；
- 隐瞒或披露媒介只改变知情关系，不永久封锁隐士和主线；
- 机关局部软锁必须在 `60` 秒内提供修复、绕行或公开重置；
- 重置不回滚已提交的学习证据、角色关系、生态身份、碎片激活或水流分配；
- 媒介本体和碎片不能被丢弃、出售、复制或因普通战败消失；
- 三方水流选择、节点同步、大型生物状态和关键披露必须跨保存、区域重置和进程重启保持一致；
- 第一章结尾生成的远方位点线索只能来自已提交的地下节点同步，不能因重新读档重复奖励。

## 11. 正式 UI 与美术边界

- 正式入口使用全屏游戏画面和最小常驻 HUD；
- 任务、学习、声望与媒介分别使用按需打开的可关闭面板；
- 审计按钮、状态注入和世界尺度切换仅保留在开发模式；
- 首期角色使用比例正常的中性人类基础角色，并具备移动、跳跃、攀爬、受击、工具和基础施法动画；
- 先制作到达山脊与聚落两个视觉样板，批准比例、相机、森林层次、古代／当代材料语言和角色动画后，再扩展剩余地点；
- 正式贴图与音频从私有素材仓通过许可、来源和哈希审批后导出到公开仓。

## 12. 现有逻辑的迁移原则

现有学习证据、WAL、生态身份、尸体加工、贸易、设施机关、安全训练场和保存逻辑继续复用，不因重写剧情而删除。

需要迁移的旧假设：

1. 移除 N00／N01 提前施法和新档直接可用媒介；
2. 把旧 `service_channel` 合并为水轮峡谷的下层维修子区；
3. 新增地下秩序节点，不用旧矿道入口代替高潮；
4. 把回流任务的完美双完成改为三方临时优先分配；
5. 将三小时主动课程收敛为五个核心词，结构粒子单独统计；
6. 新增大型半水生生物及持续巢穴／幼体状态；
7. 将现有面板式 RPG 入口降为开发审计模式，建立正式全屏入口。

## 13. 验收标准

### 13.1 剧情与节奏

- 新档主线中位目标为 `180` 分钟，首次正常范围为 `150–240` 分钟；
- 玩家在发现媒介前完成至少一次普通工具设施行动；
- 隐士教学发生在媒介发现之后、第一次正式施法之前；
- 大型生物危机和地下节点形成连续双段高潮；
- 玩家能从环境、角色和记录三个来源理解旧改道，而不是阅读单一说明面板；
- 结尾必须提交且展示三种临时水流优先方案之一。

### 13.2 玩法与学习

- 主线强制击杀数为 `0`；
- 五词均有首次情境和至少一个不同的迁移情境；
- 工具路线可以完成主线，但不写入虚假语言掌握；
- 媒介碎片不直接授予词义、MP 或自动施法；
- 安全训练场保持可选，攻击资格不阻挡地下节点或离开森林。

### 13.3 状态与后果

- 大型生物的安抚、迁徙、驱离、受伤或死亡保持身份并可回访；
- 三方水流状态分别改变居民生活、湿地生态、价格／补给和路线；
- 媒介披露路径改变知情角色，但均可找到隐士并继续主线；
- 保存、读档、区域重置和重启不得复制碎片、奖励或任务提交；
- 第一块碎片完成同步后只生成一次其他位点线索。

### 13.4 交付质量

- 正式 UI 无需开发按钮即可完成第一章；
- 七张主线地点和两张可选地点均有正式入口、出口、恢复路径和视觉职责；
- 到达山脊、聚落、主角、媒介、隐士和大型生物的正式资产均通过来源与许可审计；
- Windows 键鼠和手柄完成主线后，再进入 Android 触控与性能验收。

## 14. 明确推迟的内容

以下内容不进入本规格的首期实现：其他种族和起源的完整序章、王族正式名称与家系、中段身份揭示、远方位点的可玩地图、敌对意识的正式名称与终局、完整 `pu-120` 活动、Android 商店发布。

这些项目可以保留数据接口和不泄底的叙事线索，但不能占用森林第一章正式素材生产预算。
