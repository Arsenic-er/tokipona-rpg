# 世界观与产品边界决策日志

- 状态：访谈进行中，不作为最终世界规则权威
- 建立：2026-08-21
- 适用分支：`codex/world-scale-prototype`

## 1. 日志职责

本文记录世界观、玩家旅程、语言学习与工程边界访谈中已经确认、部分确认和推迟的决定，防止聊天结论丢失或被误写成既定规则。

- 本文是开发决策日志，不替代 W-01《世界规则》。
- 访谈全部结束并经用户批准后，结论再分别进入 W-02《历史与冲突》、W-03《地区与人物》、W-04《玩家旅程》及对应玩法规格。
- 在正式规格获批前，不因本文内容修改现有玩法逻辑、存档协议或视觉原型。
- `已确认` 表示方向已经选定；`部分确认` 表示核心方向确定但仍有下游边界；`推迟` 表示等待前置设计。

## 2. 第一轮：玩家、核心体验与世界结构

| 问题 | 状态 | 决定 |
|---|---|---|
| Q1 玩家是谁 | 已确认 | 当前主角是未知身份的外来人类旅行者；未来扩展多起源、多种族。 |
| Q2 核心体验 | 已确认 | 以理解世界规律并利用语言、物理和环境改变世界为主；怪物、Boss、采集与生存丰富内容，但击杀不必是主线。 |
| Q3 文明阶段 | 已确认 | 以古代魔法文明崩塌后的遗迹世界为主；当代技术近似中世纪，存在冷兵器和早期火枪。 |
| Q4 魔法本质初选 | 被 Q8 细化 | 真言与古代魔法编程系统兼有，后续统一为“原生共鸣＋古代人造接口”。 |
| Q5 情绪与危险 | 已确认 | 不锁定单一情绪；不同环境可温暖、神秘、忧伤或危险，整体以冒险 RPG 为主。 |
| Q6 世界地图 | 已确认 | 一个区域一张横版地图，通过出口切换；不做一张无缝开放世界。 |

## 3. 第二轮：身份、魔法与文明崩塌

| 问题 | 状态 | 决定 |
|---|---|---|
| Q7 未知身份 | 已确认 | 主角失忆，过去是长期主线谜团。 |
| Q8 真言与技术 | 已确认 | 世界天然存在难以控制的概念共鸣；古文明将其整理为有限词汇、语法、媒介和安全规则。 |
| Q9 崩塌原因 | 已确认 | 真相由多重原因构成。古文明过度抽取维持世界秩序的能量，导致光暗秩序和现实规则失效，并产生异常群落与怪物。 |
| Q10 当代魔法知识 | 已确认 | 普通人已失去施法知识；主角、少数隐士、山中某些生物与精灵仍可能学习或使用。普通人仍看得见遗迹和异常现象。 |
| Q11 初始动机 | 已确认 | 主角先为生计接受护送、修复、探索和狩猎等工作，逐渐卷入古文明与自身身份谜团。 |
| Q12 Boss 边界 | 已确认 | 主线可以要求解决 Boss 引发的问题，但允许击杀、驱逐、安抚、封印或绕行等不同方案。 |
| Q13 泰拉瑞亚参考 | 已确认 | 只参考不同地形、时段与状态对应不同怪物群落的逻辑；不以其采矿建造为主要参考。主要系统参考《Noita》。 |

## 4. 第三轮：底层能量、异常与 Noita 参考边界

| 问题 | 状态 | 决定 |
|---|---|---|
| Q14 “魔法遗忘” | 已确认 | 人们知道遗迹、怪物和异常力量存在，但失去了施法语言、操作方法与理论，只会使用少数仍工作的遗物。 |
| Q15 世界秩序能量 | 部分确认 | 存在维持光暗、正邪、动静、元素守恒和时间推进的底层能量。过度抽取使规则局部失效，产生怪物与奇异物理。名称暂未冻结。 |
| Q16 光暗含义 | 已确认 | 光暗本身不是简单善恶阵营；不同失衡均可形成危险或稳定的群落。社会可以把自然倾向解释为正邪。 |
| Q17 主角施法能力 | 已确认 | 主角具有罕见共鸣感知，并在开篇主线获得受损的古代媒介；修复媒介能反向提升魔法能力。 |
| Q18 Noita 必须参考 | 已确认 | 必须包含：像素级材料反应、结构化法术组合、可破坏地形、连锁反应、自身法术和环境可伤害玩家、怪物/NPC 遵守相同规则。明确不采用程序生成主地图和整局清档式 Roguelike。 |
| Q19 怪物生态 | 已确认 | 普通怪物由区域、时段、天气、光暗失衡和玩家行为共同决定；重要生物、Boss 与受影响种群具有持久状态。 |
| Q20 崩塌年代 | 已确认 | 古文明崩塌距今约 300–500 年。 |

## 5. 第四轮：现实规则与玩家代价

| 问题 | 状态 | 决定 |
|---|---|---|
| Q21 正义与邪恶 | 已确认 | 宇宙不直接裁决人类道德。底层能量维持的是自然倾向与秩序，文明再将其解释为正义、邪恶、保护或侵蚀。 |
| Q22 普通施法与过载 | 已确认 | 普通施法几乎不伤害世界；玩家可主动解除限制施放超规格巨型魔法，并让区域承担长期代价。 |
| Q23 异常物理 | 已确认 | 异常区具有可观察、可重复、可实验和可利用的局部规则，不采用不可推理的纯随机混乱。 |
| Q24 时间异常 | 已确认 | 存在时间停滞、加速、循环或过去景象重叠；当前不开放自由时间旅行与任意改写时间线。 |
| Q25 玩家与媒介分工 | 已确认 | 玩家学习词义、语法和材料规律；媒介决定安全组合、表达承载和更深共鸣。玩家拥有最大/当前 MP，MP 是施法强度上限的重要因素。 |
| Q26 地形持久化 | 已确认 | 关键结构、路线、资源开采和重大污染持久保存；无关碎屑、烟雾和小范围流体在卸载时结算为稳定状态。 |
| Q27 死亡 | 已确认 | 玩家返回安全点；正式提交的世界变化保留，未提交的战斗与局部变化回滚，并损失部分普通随身资源。 |

## 6. 第五轮：力量模型、种族、怪物与起始地区

| 问题 | 状态 | 决定 |
|---|---|---|
| Q28 四层力量模型 | 已确认 | 分离为：维持现实的底层能量、可恢复的环境共鸣、角色自身 MP、负责编译与稳定施法的古代媒介。底层能量名称“律能”仅为工作名。 |
| Q29 媒介人格 | 已确认 | 没有完整人格；只显示破碎记录、警告、图形和残缺记忆。 |
| Q30 失忆与媒介 | 已确认 | 早期不直接揭晓；线索表明失忆、媒介损坏和一次底层能量异常可能属于同一事件。 |
| Q31 种族来源 | 已确认 | 古老独立种族、崩塌后变异族群和共鸣生命均可存在；“精灵”只是其中一个待定义族群。 |
| Q32 怪物来源 | 已确认 | 异常能量生命、变异动植物、古代守卫/实验体/失控设施并存；“怪物”是当代人的危险俗称，不是单一生物分类。 |
| Q33 火枪技术 | 已确认 | 当代工匠生产普通早期火枪；古文明共鸣远程武器属于稀有且不同的技术体系。 |
| Q34 第一座山谷 | 已确认 | 山谷位于受损的世界能量循环节点上；表层是供水与生态问题，地下遗迹与主角媒介有关，但山谷不是世界中心。 |

## 7. 第六轮：成长、构筑与区域旅行

| 问题 | 状态 | 决定 |
|---|---|---|
| Q35 MP 成长 | 已确认 | 角色通过学习、共鸣实验、训练与理解世界提高自身能力；媒介提高效率、结构容量和安全上限。玩家应在游玩中真实学习道本语，学习模型参考真实学习效率与行为。 |
| Q36 媒介修复 | 已确认 | 核心修复随主线；分析、储存、并行结构、环境取能和过载控制等附加模块可选择。 |
| Q37 法术构筑 | 已确认 | 使用已理解的词语、修饰、方向、触发条件和媒介槽位搭建结构，不使用任意自由文本作为正式执行入口。 |
| Q38 巨型魔法 | 已确认 | 必须主动解除媒介限制，先展示可预见区域代价，再二次确认。普通材料连锁仍可能意外造成局部伤害。 |
| Q39 死亡损失 | 已确认 | 世界时间推进，部分未存放普通材料掉落；装备、媒介、关键物品和已提交进度保留。 |
| Q40 区域旅行 | 已确认 | 通过地图边缘、道路、洞口和交通设施切换横版地图；发现路线后可从安全地点快速旅行。 |
| Q41 山谷之后 | 已确认 | 旧矿揭示山谷只是网络节点之一，并开放两至三个方向不同的区域，形成半开放区域选择。 |
| Q42 多种族与起源 | 已确认 | 种族影响身体与环境适应；起源影响初始知识、关系和装备，但不锁死主线与核心魔法，不设置单一最佳种族。 |

## 8. 第七轮：真实语言学习边界

| 问题 | 状态 | 决定 |
|---|---|---|
| Q43 目标用户与平台 | 已确认 | 面向全球各语言的青年与成年人；先完成中文；正式目标平台为 Windows 与 Android，并从架构上支持多语言、多平台。 |
| Q44 学习目标 | 已确认 | 掌握核心词汇与基础语法，能够理解并主动组成简单句；不虚称仅凭游戏达到完整流利。 |
| Q45 真实语言与施法协议 | 已确认 | 现实词义与基础语法保持准确；媒介触发器、方向槽和并行结构明确标为虚构施法协议。部分当地族群可用道本语日常交流，并使用表意文字。 |
| Q46 学习属性 | 已确认 | 底层按词语/结构记录接触、识别、主动回忆、生产、跨情境迁移和延迟保持；玩家只看到简明总览。 |
| Q47 学习活动 | 已确认 | 通过观察、施法、修理、预测、委托和跨环境应用学习，并提供可选复习册，不以弹窗考试为主要形式。 |
| Q48 自适应学习 | 已确认 | 根据正确率、反应时间、提示依赖、错误类型、复习间隔和迁移表现调整内容；学习为辅助，游玩为主。 |
| Q49 发音与听力 | 已确认 | 当前不把发音、听辨、跟读或语音识别作为目标；像素音效可承担普通对话声音，核心资源优先投入玩法。 |
| Q50 主线语言门槛 | 已确认 | 环境、工具或求助路线可暂时绕过；关键魔法能力只在玩家后来表现出真实理解后解锁。 |

## 9. 第八轮：文字、语言社群与崩塌责任

| 问题 | 状态 | 决定 |
|---|---|---|
| Q51 表意文字使用范围 | 部分确认 | 只有古代碑文和某些当地语言社群使用表意文字。是否直接采用标准 `sitelen pona`、是否允许风格化变体仍待确认。 |
| Q52 当代语言社群 | 推迟 | 哪些种族或社群保留道本语，等待完整种族与文化设计后决定。暂不使用“原住民”作为未定义的统一族群名称。 |
| Q53 日常语言与施法 | 已确认 | 会说日常道本语不等于会施法；还需要共鸣感知、MP、媒介和专门施法结构。 |
| Q54 NPC 对话生产 | 已确认 | 开发阶段可辅助生成，但必须通过规则校验和人工/社群审阅；运行时只使用批准文本或受限模板。用户后续提供道本语词典与教科书作为资料。 |
| Q55 学习系统可见性 | 已确认 | 调度逻辑默认隐藏，在任务与环境中自然复现；学习日志可选查看。 |
| Q56 多语言内容源 | 已确认 | 使用独立于界面语言的结构化语义内容源；中文、英语等为本地化层，道本语内容保持独立。 |
| Q57 古文明过度抽取动机 | 已确认 | 起初服务供水、农业、交通和灾害防护；随后基础设施依赖、精英延寿与国家军备竞赛共同阻止文明减速。 |

## 10. 第九轮：古代政治与当代社会

| 问题 | 状态 | 决定 |
|---|---|---|
| Q58 古代文明的政治形态 | 已确认 | 古代文明不是单一帝国，而是多个王国、城邦与族群共同使用共鸣技术；彼此既合作，也竞争。 |
| Q59 古代知识断裂的原因 | 已确认 | 知识失传是复合结果：施术者大量死亡、媒介与能量网络损坏、知识遭到主动压制或销毁，同时仍有隐士与少数社群保存碎片。 |
| Q60 当代政治格局 | 已确认 | 当代世界由碎片化城邦、小王国、自治聚落、贸易联盟与宗教领地构成，不存在统一世界政权。 |
| Q61 宗教对世界失衡的解释 | 已确认 | 不同宗教与思想传统对世界失衡有不同解释；叙事不会在早期宣布某一种解释是唯一真相。 |
| Q62 标准化与语境传统 | 部分确认 | 保留两种思想传统及其历史冲突：古代后期曾出现试图以“一词一义”降低魔法事故的标准化传统或机构；崩塌后则有强调语境、多义与实践经验的游历传统继续传播碎片知识。两者的历史作用、思想冲突与后继群体保留，但“定言院”“听行者”只是工作名，待种族、文化与语言社群设计完成后重新命名。 |
| Q63 第一山谷聚落 | 已确认 | 第一山谷聚落是旧道路与水利遗迹旁的边境小聚落，依靠设施维护、狩猎、农业和有限贸易生存。 |
| Q64 终极反派与冲突结构 | 已确认 | 世界没有单一终极反派；主要冲突来自失衡的自然规律、生态变化、政治与制度选择，以及各方都具有部分正当性的利益冲突。局部恶人和 Boss 可以存在，但不垄断世界问题的根源。 |

## 11. 第十轮：第一章开局与叙事交付

| 问题 | 状态 | 决定 |
|---|---|---|
| Q65 主角进入第一山谷 | 已确认 | 主角在异常现象后于山谷边缘醒来，身份不明且记忆残缺。玩家应尽快获得控制权，通过环境痕迹找到聚落，而不是先观看长篇说明。进入聚落后，通过接工作获得近期生存动机。 |
| Q66 受损古代媒介的获得 | 已确认 | 主角在第一条主线的水利或道路遗迹中找到受损媒介；发现时它几乎无法使用。玩家先凭工具、观察和普通行动解决问题，媒介之后才对基础且真实的道本语线索产生第一次响应。 |
| Q67 聚落对外来者的态度 | 已确认 | 聚落对主角谨慎但务实：允许暂住和接零工，信任随实际行动及其后果逐步增加，不立即将主角视为救世主。 |
| Q68 第一章的信息来源 | 已确认 | 由至少三种不完整视角共同提供信息：聚落劳动者、保存碎片知识的隐士、外来学者或商人。各方只知道局部事实，也可以互相矛盾；玩家通过环境证据和行动结果判断。 |
| Q69 第一山谷怪物生态 | 已确认 | 怪物种类、路线与行为同时受时间、天气、光暗失衡和玩家修复行为影响。重要个体与生态变化应具有持续性，不采用单纯离屏刷新。 |
| Q70 世界观的叙事方式 | 已确认 | 以环境变化、短对话、任务后果和碑文碎片为主，并提供可选日志整理已发现事实；不通过开场电影、长篇 NPC 讲解或提前剧透直接灌输世界设定。 |
| Q71 第一章高潮 | 已确认 | 第一章高潮是恢复山谷的一处关键秩序节点。相关大型生物或异常可以战斗、引开、安抚或绕过；Boss 可以存在，但击杀不是唯一解法，也不是恢复节点的必要条件。 |

## 12. 第十一轮：开场因果、媒介与首个矛盾

| 问题 | 状态 | 决定 |
|---|---|---|
| Q72 主角在山谷醒来的原因 | 已确认，架构需扩展 | 当前人类旅行者起源采用局部秩序异常造成的意外空间偏移；媒介可以与异常有关，但不将主角明确写成被召唤的天选者。角色创建、存档和开场流程必须为未来的多起源、多种族线路保留扩展点，不把这一次开场硬编码成所有角色共有历史。 |
| Q73 主角的开场物资 | 已确认 | 主角拥有破损旅行装备、一件普通工具或武器及少量补给，没有可用魔法能力。开场不是赤手空拳，也不预置强力装备。 |
| Q74 受损媒介的初始形态 | 已确认 | 媒介最初是小型破损核心或铭文构件，之后可安装进玩家选择的法杖、护具、武器或工具。媒介功能与角色外观、职业和装备构筑解耦。 |
| Q75 第一山谷的迫切危机 | 已确认 | 古代水利与道路系统持续失效，使饮水、农田、贸易和湿地生态同时受损；怪物与异常变化是这种失衡的结果和放大器，而不是唯一问题。 |
| Q76 第一位聚落关系人物 | 已确认 | 玩家首先与负责水道、道路或公共设施的劳动者建立关系。此人了解设施、日常生活和现实困难，但不掌握完整世界真相；早期教学通过共同工作发生。 |
| Q77 第一位隐士的作用 | 已确认 | 隐士是语境化、实践型碎片知识的传承者，能够指导玩家观察共鸣，但只掌握部分事实，也可能隐瞒、误判或受自身立场限制。 |
| Q78 第一章设施的解决路线 | 已确认 | 工具修理、环境操作、语言魔法和战斗控制可以组合使用；不同做法产生不同生态与社会后果。不得把关键设施锁成唯一顺序、唯一派系或必须击杀的路线。 |

## 13. 第十二轮：第一山谷的空间、社会与持续后果

| 问题 | 状态 | 决定 |
|---|---|---|
| Q79 第一山谷的首发地图规模 | 已确认 | 首发第一山谷由 7 张主线区域地图和 2 张可选区域地图组成。每个地点是独立横版区域地图，通过明确出口切换，不合并成无缝开放世界。现有地点逻辑可以迁移为山谷边缘、溪流旧路、聚落、水轮设施、蓄水池、回流水道和秩序节点；洞穴或兽穴、安全训练场作为可选地点，最终名称与地形布局仍待设计。 |
| Q80 水利危机造成的社会矛盾 | 已确认 | 聚落居民需要饮水和农田，湿地使用者需要生态流量，商旅希望优先修通道路；现有资源不足以立即满足所有诉求。各方拥有部分正当性，不用邪恶首领或教派破坏替代结构性冲突。 |
| Q81 第一次修复的结果 | 已确认 | 玩家第一次只能完成带有优先级的临时分配，短期改变聚落生活、交通和生态；后续通过探索、学习和设施升级，可以逐步实现更完整的平衡。早期选择有后果，但不永久锁死主要内容。 |
| Q82 古代媒介的交流方式 | 已确认 | 媒介通过符号、残缺图形、温度、震动、短促像素音效和环境响应表达，不具备清晰人格，也不充当讲解世界观的智能助手。 |
| Q83 主角身份与记忆的揭示 | 已确认 | 通过身体习惯、随身物品、他人反应、错误或不完整记忆以及媒介残片逐步拼合；证据可以互相矛盾，玩家需要形成判断，不能靠升级媒介直接播放绝对真实的完整答案。 |
| Q84 玩家战败 | 已确认 | 常规战败表现为被附近居民或同伴救回，损失时间、部分物资或区域机会；受损媒介不提供无限复活。真正的剧情死亡仍然具有重量。具体惩罚必须可恢复，不能形成无法继续的资源死锁。 |
| Q85 第一章完成后的持续变化 | 已确认 | 水位、植被、怪物路线、居民工作、商店供给和旅行路径会根据玩家方案改变，并在离开后继续演化。第一山谷是可回访、持续变化的区域，不是一次性教学关。 |

## 14. 第十三轮：第一山谷地图、生态冲突与核心词

| 问题 | 状态 | 决定 |
|---|---|---|
| Q86 第一山谷的地点组合 | 已确认 | 7 张主线地图暂定为到达山脊、溪流旧路、边境聚落、水轮峡谷、高地蓄水池、回流湿地和地下秩序节点；2 张可选地图暂定为兽穴洞窟与安全训练场。名称是描述性工作名，最终名称等待地域文化设计。 |
| Q87 区域连接方式 | 已确认 | 聚落是交通中心，上游设施、下游湿地与旧路形成分支；部分出口随设施修复或世界状态开放。区域之间通过明确出口切换，不依赖纯菜单传送，也不在开场开放所有地点。 |
| Q88 第一次水流分配 | 已确认 | 玩家可优先保障聚落生活与农田、湿地生态，或旧路与贸易。三种方案分别影响居民、生态和经济；后续设施升级与知识增长允许逐步达成更完整的平衡方案。 |
| Q89 早期选择的严重程度 | 已确认 | 选择必须明显改变任务、价格、怪物、NPC 工作与旅行路线，但结果可恢复，不永久删除核心剧情，也不要求不了解系统的新玩家重新开档。 |
| Q90 第一章大型生物 | 已确认 | 大型生物是被水位和光暗失衡赶出原栖息地的本地生物，本身不是邪恶。玩家可以战斗、引开、喂食、安抚，或通过改变环境使其离开；不同处理方式产生持续后果。 |
| Q91 地下秩序节点的异常 | 已确认 | 节点周围会局部出现重力、时间流速、物质状态和元素守恒失效，形成可利用也危险的物理现象。它是第一章对系统性物理互动的集中展示，但受初期 MP、媒介损坏程度和玩家掌握状态限制。 |
| Q92 第一章核心道本语词 | 已确认 | 第一章重点让玩家掌握 `telo`（水）、`tawa`（移动）、`lili`（小）、`suli`（大）和 `wawa`（力量／能量）。五词必须在环境观察、修理、行动、回忆和跨情境使用中重复出现并逐渐组合；工具路线可以推进主线，稳定魔法则要求真实理解证据。 |

## 15. 第十四轮：边境聚落的政治、经济与人物关系

| 问题 | 状态 | 决定 |
|---|---|---|
| Q93 聚落治理 | 已确认 | 聚落由设施维护者、农户代表和商旅代表组成务实议事会。不同席位分别承担公共设施、生活生产与外部交通诉求；任何单一成员都不能代表整个聚落。 |
| Q94 与外部政权的关系 | 已确认 | 聚落名义上向附近城邦或小王国纳税，但因道路损坏、距离遥远和长期失衡而高度自治。未来道路恢复后，税吏、官员、军队或商业代理重新出现，可以形成新的合法性冲突。 |
| Q95 日常交易方式 | 已确认 | 外部贸易使用钱币；聚落内部同时使用欠账、工分、互助和实物交换。主角可以通过工作获得基本生存条件，但跨区域装备、稀缺材料与正式贸易仍需要钱币。 |
| Q96 初始火枪的普及程度 | 已确认 | 少量猎人、守卫和富裕商队拥有装填缓慢、弹药昂贵的早期火枪；异常区域可能影响可靠性。火枪是可用但稀缺的工具，不取代冷兵器、弓箭、劳动工具和语言魔法。 |
| Q97 第一位设施劳动者 | 已确认 | 此人务实、熟悉水道并怀疑陌生人，其家人或生计直接受断水影响；角色首先是聚落劳动者和利益相关者，不是隐藏魔法导师或单纯教学吉祥物。姓名、外观、年龄和家庭结构待角色设计。 |
| Q98 水利失效的人为历史 | 已确认 | 一部分居民曾私自改变水流以度过过去的旱季，当时缓解了生存危机，却加剧了今天的系统性失衡。调查需要区分当时动机、实际受益者、被转移的代价与今天的责任，不能把问题简化成蓄意破坏。 |
| Q99 隐士与聚落的关系 | 已确认 | 隐士曾帮助聚落，也因异常事故和知识隐瞒受到怀疑；双方仍交换药材、情报和修理材料。隐士与议事会都不是天然可信的唯一权威，玩家需要用世界证据核对其说法。 |

## 16. 第十五轮：媒介兼容、法术构造与魔法硬边界

| 问题 | 状态 | 决定 |
|---|---|---|
| Q100 主角启动媒介的原因 | 方向确认，剧情推迟 | 当前默认人类旅行者起源拥有古代王族血缘，因此能与这枚受损媒介建立兼容；具体王族、家系、继承关系、主角为何流落以及揭示事件留到后续剧情设计。血缘只解释兼容性，不自动赋予道德正确性、统治权、完整知识或无需学习即可施法的能力。未来多起源、多种族线路必须允许通过其他媒介、仪式、训练、生理共鸣或技术方式进入魔法系统，不能都被改写为同一王族后裔。 |
| Q101 媒介成长结构 | 已确认 | 主线修复基础核心，逐步解锁感知、塑形、储存和并行结构；支线提供可替换模块。媒介决定法术组织能力，角色 MP 独立决定可承受与输出的强度，两条成长线不得合并成单一伤害等级。 |
| Q102 法术构造 | 已确认 | 玩家使用已经理解的道本语词和结构组合受约束的语义表达，也可以实验未知组合；结果必须由稳定、可复验的语义和物理规则决定。媒介提供有限预览，不使用任意自然语言的临场 AI 解释，也不退化为纯固定技能栏。 |
| Q103 错误施法与超规格输出 | 已确认 | 普通语法或结构错误应拒绝施放，或只造成少量可恢复 MP 损失；只有玩家得到明确警告后主动选择超规格输出，才可能产生反冲、伤害、设备损坏或区域变化。实验不应受到随机即死惩罚。 |
| Q104 区域共鸣的可见性 | 已确认 | 默认通过环境表现、媒介反馈和仪器显示充盈、波动、衰减、枯竭等可读状态；高级工具或辅助设置可以显示更精确信息。不把所有区域信息永久压缩成裸数值，也不能完全隐藏决策依据。 |
| Q105 媒介载体 | 已确认 | 核心可在安全地点安装进法杖、护具、武器或工具。载体改变施法速度、稳定性、容量和物理用途，但不永久锁定职业；系统需兼容未来的角色外观与装备自定义。 |
| Q106 魔法的绝对边界 | 已确认 | 魔法不能无中生有地创造无限物质、不能把日常死亡变成廉价复活、不能直接改写人格，也不能自动翻译未知知识。所有效果必须有来源、代价、MP、媒介能力和环境状态约束，边界不能随剧情临时改变。 |

## 18. 已知冲突与后续迁移

以下内容在正式设计批准后需要对照更新，当前不直接改写：

1. `docs/design/README.md` 仍把项目描述为“竖版 2D 像素动作 RPG”，而最新决定是全屏呈现的横版区域地图。
2. W-01 当前把共鸣语描述为跨地区魔法协议；新决定增加了古文明崩塌、知识失传和少数语言社群，需要重写历史层而不是破坏语言规则层。
3. W-01 尚未区分世界底层能量、环境共鸣、个人 MP 和古代媒介四层来源。
4. 当前视觉原型固定 9:16 且只接通少量场景；它是尺度实验，不代表获批后的正式镜头或区域旅行。
5. 现有音频规划若包含发音课程，需要按照 Q49 降级；普通对话继续使用像素音效和文字。
6. 当前语言学习实现需审计是否真正区分角色属性与玩家掌握证据，并按 Q46/Q48 补齐学习行为模型。
7. 当前单一起源开场、角色初始化和存档字段必须拆出起源标识与起源专属序章入口，避免将“异常卷入山谷”写成未来所有角色的共同历史。
8. 当前第一章逻辑需要重组为 7 张主线区域地图与 2 张可选地图，并把水利临时分配及其生态、经济、NPC 与怪物后果写入可持久化区域状态；不得删除已经完成的底层事务、学习、生态和设施逻辑。
9. 当前章节课程与运行时内容需要收敛到第一章五个核心词的可玩掌握路径；其他词可以出现，但不得稀释 `telo`、`tawa`、`lili`、`suli`、`wawa` 的观察、主动回忆、生产和迁移证据。
10. 当前能力与媒介模型需要明确拆分角色 MP、媒介基础结构、可替换载体模块、区域共鸣和词语掌握证据；禁止用王族血缘绕过这些门禁。

## 19. 仍待决定的主要分支

- 世界底层能量、古代媒介和古文明的正式名称。
- 表意文字是否严格采用 `sitelen pona`，以及古代碑文字形允许怎样的视觉变体。
- 当代种族目录、文化、语言社群与“精灵”的具体定义。
- MP 永久成长、恢复速度、媒介模块和超规格魔法的精确规则。
- 各城邦、小王国、自治聚落、贸易联盟与宗教领地的具体名称、成员结构及相互关系。
- 古代标准化传统与崩塌后语境传统的正式文化名称；“定言院”“听行者”不得直接视为最终名称。
- 议事会所隶属政权的身份、税赋契约和道路恢复后重新介入山谷的方式。
- 第一位设施劳动者、议事会成员、隐士、商旅和相关家庭的具体人物设计。
- 过去私改水流事件的参与者、受益者、代价承担者与现存证据。
- 水利或道路遗迹内发现媒介的具体事件设计。
- 不同宗教、行会与隐士群体对遗迹、失衡和光暗群落的具体解释。
- 多起源、多种族角色创建的共享字段、起源专属序章和汇入第一章的规则。
- 默认人类旅行者所属古代王族的身份、历史责任、血缘流散、主角家系与揭示节奏；以上均不得提前当作公开剧情事实。
- 其他起源获得媒介兼容或魔法入口的具体机制。
- 第一山谷 7+2 地点的最终文化名称、精确出口拓扑、视觉主题和持续状态矩阵。
- 临时水流分配的具体选项、短期代价、可逆条件与最终平衡路线。
- 第一章大型生物的物种、生命周期、栖息需求、非战斗处理条件与后续生态作用。
- Android 与 Windows 的输入、性能、存档和 UI 边界。
- 用户后续提供的道本语词典、教科书和社区资料的来源、版本、许可与审阅流程。
