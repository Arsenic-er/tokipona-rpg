# 世界观与森林第一章一致性审计

- 状态：访谈收口审计 v0.1
- 日期：2026-08-28
- 决策输入：[《世界观与产品边界决策日志》](00-worldbuilding-decision-log-zh.md) Q1–Q178
- 对照范围：W-01、设计索引、第一章章节／地区／任务／生态数据、当前 RPG 与世界尺度原型

## 1. 审计结论

178 项访谈决定形成了可以实施的共同方向，没有发现必须推翻整个世界观的致命矛盾。核心因果链成立：

```text
世界底层自然秩序
→ 古代多政体把概念共鸣工程化为道本语施术网络
→ 长期过度抽取、军备竞赛、知识压制与网络损坏
→ 现实规则失衡、生态变异、古代网络形成分布式敌对意识
→ 当代碎片化社会生活在遗迹与异常之间
→ 默认人类旅行者因异常进入森林山谷
→ 通过劳动发现受损媒介，处理供水、生态与历史责任
→ 逐区调查并决定如何处置旧网络及其敌对意识
```

当前不能直接进入森林正式制作。需要先解决 4 项规范冲突和 7 项首章迁移阻断；其他世界地区、种族和王族剧情可以推迟，不阻挡森林垂直切片。

## 2. 必须立即校正的规范冲突

| ID | 冲突 | 结论与统一规则 |
|---|---|---|

| C-03 | Q27 把常规失败称为死亡并返回安全点，Q84 又要求常规战败是获救或撤离，真正死亡保有重量。 | 以 Q84 为准。普通玩法循环使用“战败／失能”，由有来源的救援、拘留或撤离结算时间与物资；真正剧情死亡不自动复活。低声望地区的救援者与拘留结果需单独定义。 |

## 4. 现有首章实现与新基线的阻断差异

### P0-01：媒介取得时间与开场施法冲突

新基线要求主角先用普通工具抵达聚落，并在第一次公共设施工作中发现媒介。当前章节数据从抵达段就聚焦 `telo`，`PrologueArrivalStream` 也支持在 N01 显化水；能力表在新档直接初始化法器槽位。

统一迁移：

1. N00/N01 仅允许移动、普通工具和环境路线；
2. N02 接受公共设施工作；
3. 工作改变水位，打开维护室并取得受损核心；
4. 从 N03 或独立短教学点开始引入 `telo`；
5. 工具路线继续有效，媒介发现不能被随机掉落或角色赠送替代。

### P0-02：第一次水流分配被旧任务写成完美双完成

新基线要求聚落、湿地、旧路贸易三种临时优先级，第一次不能完美满足全部诉求。当前 [`ch01-return-flow.v0.1.yaml`](../../../data/tasks/ch01-return-flow.v0.1.yaml) 原子同时写入 `settlement_supply_stable` 与 `wet_meadow_restored`，没有贸易优先状态。

统一迁移：把单一完成标记改成带版本的水流分配状态，至少包含 `settlement_priority`、`wetland_priority`、`road_trade_priority` 与后期 `balanced_upgrade`。每种方案都要写水位、NPC 工作、价格、怪物迁徙、道路和修复机会，且可以通过后续工程逐步改善。

### P0-03：7+2 地图与当前 10 节点拓扑不一致

新基线的 7 张主线图是到达山脊、溪流旧路、边境聚落、水轮峡谷、高地蓄水池、回流湿地和地下秩序节点；2 张可选图是兽穴洞窟与安全训练场。当前地区数据拥有 arrival、stream、settlement、waterwheel、service_channel、high_cistern、den、return、safe_range、old_mine_threshold 共 10 个节点，且没有承担第一章高潮的地下秩序节点。

迁移前必须在关卡规格中明确以下取舍：

- 将 `service_channel` 合并进水轮峡谷或高地蓄水池，或者把其下层重新定义为地下秩序节点；
- `old_mine_threshold` 只能作为通往下一地区的边界入口，不计作森林第一章完整地图；
- 兽穴与安全训练场保持可选；
- 地下秩序节点承担第一章高潮，而不是只用回流观察结束主线。

### P0-04：第一章核心词与旧 P0-12／14 词预算不一致

新基线把 `telo/tawa/lili/suli/wawa` 设为第一章五个主动核心词。现有 W-01 和 README 保留 14 个候选内容词；`p0-curriculum.v0.1.yaml` 又为前三小时规划 12 词状态，并把 `wawa` 放在 P0 之外。

统一迁移：五词是三小时主线唯一主动掌握目标；其他词可以作为环境、对话或可选支线的接受性暴露，但不设三小时发现 10–12 词的发布门槛。`o/li/e` 作为结构粒子单独统计，不与五个内容词混算。完整 `pu-120` 仍是远期语料目标，不进入森林首章素材完成定义。

### P0-05：大型半水生生物尚不存在

现有生态只对兔、狐、蝙蝠和泥蛙进行部分投影，N06 的核心是狐狸巢旁路。新基线需要一个具有巢穴、幼体、食物、水道改造、警告、迁徙、安抚、引导与永久死亡状态的大型半水生生物。

统一迁移：保留现有小动物与狐狸逻辑作为可选生态层；新增大型生物独立生命身份和种群／巢穴契约，不把狐狸放大或改名冒充 Boss。大型生物与水流分配共享环境状态，但语言学习不得从伤害或击杀获得证据。

### P0-06：正式 UI 与当前面板式原型冲突

当前 [`rpg-main.ts`](../../../src/rpg-main.ts) 和 [`rpg.css`](../../../src/rpg.css) 持续渲染大量任务、学习、经济、设施、回流和靶场面板；世界尺度页面本身明确是 visual audit。新基线要求全屏游戏画面、最小常驻 HUD 与按需面板。

统一迁移：审计工具保留在开发模式；正式入口只暴露游戏画面、上下文互动、必要 HUD 和可关闭的任务／学习／声望／媒介面板。不得把现有按钮面板换皮后视为最终 UI。

### P0-07：森林美术与角色动画尚未形成正式资产

当前场景多为 `planned` 或灰盒状态，世界尺度页面使用抽象暗色平台；正式中性人类角色、温带混合林分层、古代石构／金属嵌件、当代木绳铁件修补、昼夜声景及半水生生物动画均未交付。

统一迁移：先制作 N00 到达山脊与 N02 聚落两个视觉样板，批准比例、材质、层次、相机和角色核心动画后，再扩展剩余森林地图。所有正式贴图和音频进入私有素材库并保留许可、来源与哈希；公开仓只接收获准导出。

## 5. 重要缺口，但不是当前逻辑冲突

以下内容尚未实现，但可以按新基线直接新增，无需推翻已有规则：

- 聚落议事会、7–9 名核心人物、外部名义政权及过去私改水流事件；
- 聚落声望、组织立场、个人关系、犯罪、通缉、有限守卫与消息传播；
- 主角起源字段、种族字段、王族线索及媒介披露分支；
- 昼夜、天气、季节、跨区迁徙及持续生态；
- 半水生大型生物的非战斗解决路线；
- 第一章战败后的救援、拘留和资源结算；
- Windows 键鼠／手柄正式输入，之后的 Android 触控与打包；
- 像素对话音、森林环境音和正式素材审批。

这些缺口不得被描述为“逻辑已完成”；现有 WAL、生态身份、加工贸易、学习证据和安全攻击资格只是可复用底层能力。

- Android 的最终性能、商店发布和触控细节。

这些项目只能保留 schema 接口与叙事占位，不得消耗森林首章的正式素材生产预算。

## 7. 森林第一章统一基线

首章实施时使用以下优先级：

1. **画面与操作**：全屏横版森林，比例正常的中性人类角色，Windows 键鼠／手柄先行；
2. **开场**：异常醒来，工具路线抵达聚落，不能提前施法；
3. **社会**：通过设施劳动取得基本信任，认识议事会的三类利益；
4. **媒介**：公共设施工作改变水位，发现维护室和受损核心；
5. **学习**：依次聚焦 `telo → tawa → lili/suli → wawa`，攻击魔法保持可选；
6. **冲突**：调查过去紧急改道、大型生物迁徙及地下节点；
7. **选择**：完成聚落、湿地或旧路贸易的第一次临时优先分配；
8. **收束**：观察持久后果，可继续森林支线或准备离开；
9. **完成门**：三小时主线、多路线、可回访、稳定保存／重启、无开发按钮、素材来源可审计。
