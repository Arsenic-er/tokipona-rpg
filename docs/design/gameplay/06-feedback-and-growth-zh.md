# G-04｜反馈与成长：P0 学习证据纵向切片

状态：实现候选 v0.2
机器真源：`data/language/learning-progression.v0.2.yaml`、`data/language/p0-curriculum.v0.1.yaml`
运行时内核：`src/learning/progression.ts`

## 1. 本轮目标

本轮把序章十二字从“地图里有字形”接成可测试的学习闭环：

```text
世界发现 → 永久调谐激活 → 环境奠义 → 两情境主动产出
         → 未见迁移 → 逻辑延迟取回 → 稳固
```

它先服务 `telo → tawa → lili/suli` 四词可玩切片，再承载其余八字。它不把答题正确率换算成伤害，也不要求连续打卡。

## 2. 四条状态轴

| 状态轴 | 是否存档 | 作用 |
|---|---|---|
| `discovery_state` | 是 | `unknown → discovered`，记录玩家在世界中见过字形。 |
| `attunement_state` | 是 | `locked → attuned`，表示字形已被永久调谐；界面可称“激活”。 |
| `visual_activation` | 否 | `dormant → activating → active`，只驱动八帧整体变亮。 |
| `learning_state` | 是 | `discovered → grounded → produced → stabilized`，只由合格证据推进。 |

永久“激活”与动画“点亮”不能共用字段。八帧动画可以反复播放、离开界面后复位；它不能授予词义、自由组合资格或熟练度。

旧关卡数据中的 `seen/available/practiced/mastered` 必须在读取边界迁移为 `discovered/grounded/produced/stabilized`。新任务只能提出证据，不能直接写“掌握”。

## 3. 调谐激活

激活需要一份通用、非稀缺、不可交易的刻印媒介，以及与该词相关的环境见证。见证用于把字形放回世界语境，不是要求玩家收集十二种一词一材料的随机掉落。

- `telo` 的见证可以是流动或盛装的水；
- `tawa` 的见证可以是正在运动的水轮；
- `kon` 的见证可以是尘埃显示出的气流；
- `soweli` 的见证可以是足迹与远处动物，而不是尸体。

激活中断或失败不消耗媒介。完成后开放读音、冥想卡和作者定义的受控试用；不会直接开放自由组合，更不会提高伤害。

## 4. 学习状态的证据门槛

### 4.1 `grounded`

玩家在作者定义的环境任务中使用或判断该词，系统返回 `parsed_grounded` 或 `executed_legal`，并且该词确实促成了世界结果。提示最高为 H1。

以下情况不能奠义：工具旁路、答案仍显示、只靠固定槽位、只凭类别颜色、任务脚本直接赠送。

### 4.2 `produced`

同一词必须在两个不同任务家族中主动取回。H0 不给词汇提示；H1 只给场景、意义或关系线索，不能显示正确词、固定槽位或答案色。

相同 `variant_hash` 无论读档、重置或换一个事件 ID，都最多记一次。达到 `produced` 后，词才进入自由组合词库。

### 4.3 `stabilized`

在 `produced` 之后，还需要：

1. 一个不属于产出基线任务家族的未见迁移；
2. 一个不属于产出基线任务家族的延迟取回；
3. 延迟取回前至少发生两个无关、已提交的世界事件；
4. 全部证据至少覆盖两个语义面。

“延迟”使用世界事件而不是现实时间，玩家不必挂机或等待第二天。下一会话正确率作为试玩留存指标，不作为卡进度的现实时间门。

未见迁移与延迟取回各自使用的规范环境指纹都必须在 `produced` 时冻结的环境基线之外；两份迁移证据之间也必须同时具有不同的环境指纹和不同的 `variant_hash`。仅更换事件 ID、任务标题或提示文本不能冒充两次迁移。

## 5. P0 十二字负荷

前三小时是内容预算，不是现实时间门。序章正式 P0 为：

| 阶段目标 | 字符 | 设计目的 |
|---|---|---|
| `produced` | `telo/tawa/lili/suli` | 建立物质、运动与长度的四词闭环。 |
| `grounded` | `seli/kiwen/awen` | 能理解并受控试用，不要求立即自由产出。 |
| `attuned` | `kon/kasi/lukin/weka/soweli` | 保持探索奖励，控制主动新词负荷。 |

`o` 与 `wawa` 是攻击资格路线中的章节教学词，不属于 P0 十二字，也不能暗中计作第十三、十四个 P0 发现。

每字至少有两个对照语境与一个“把游戏原型误当完整词义”的修复项。特别禁止：把 `kon` 固定为悬浮、把 `seli` 固定为火球、把 `kasi` 固定为治疗、把 `soweli` 泛化为所有生命，或把 `lili/suli` 的游戏长度投影说成完整词义。

## 6. 冥想练习

冥想按证据强度分五类：

1. 字形—读音识别：撤去类别颜色，使用低分辨率易混淆项；上限为发现证据。
2. 双情境辨义：两个合理情境加一个窄义陷阱；可支持奠义。
3. 场景主动取回：由世界状态重建词或表达；两任务家族后才支持产出。
4. 误解修复：分别解释 `parsed_ambiguous`、`parsed_out_of_scope`、`unparseable`，允许改述。
5. 延迟平行迁移：更换材质、对象、地点和 UI 排列，撤去固定槽位与颜色。

休息和冥想都可提供基础当前 MP 恢复，答错不能拒绝基础恢复。只有首次出现且通过去重的合格证据，才可进入最大 MP、自然回 MP、稳定性、精度、效率和范围上限的章节里程碑。机械重复没有永久收益。

## 7. 事件账本与隐私

学习 reducer 接收以下事件：

```text
glyph_discovered
glyph_attunement_completed
grounding_trial_resolved
active_retrieval_submitted
repair_completed
unseen_transfer_completed
delayed_retrieval_completed
```

情境事件必须携带 `task_family_id`、`variant_hash`、规范环境指纹、提示等级、解释状态、规范 AST 词 ID、语义面和世界结果贡献。幂等键相同且载荷相同为 no-op；幂等键相同而载荷不同为冲突。

学习存档的 `word_id` 使用裸拉丁 canonical token，例如 `telo`。`canonical_ast_word_ids` 使用 AST 节点命名空间，例如 `word.telo`；事件必须满足 `canonical_ast_word_ids` 包含 `word.<word_id>`。两种口径不能混写，UCSUR 码位也不能充当任何一种逻辑 ID。

默认不保存玩家原始自由文本。事件账本保存规范词 ID、结果码和证据身份即可。

## 8. 成长边界

- 字符发现数、答题连胜、击杀数、金币和重复施法次数均不能直接推进学习状态。
- 熟练度可改善控制、稳定、持续、MP 效率和范围上限，但不能进入物理伤害公式。
- 最大 MP 或稳固词数可以成为表达容量里程碑的候选证据，但容量仍由章节事件唯一写入。
- 任务失败、忘记冥想或答错不会导致永久退级。
- 工具路线可以推进世界目标，但不得伪造目标语言证据。

## 9. 实现与测试顺序

1. 运行时先支持 `telo` 的发现、调谐、奠义、两情境产出和延迟迁移。
2. 将同一闭环扩展到 `tawa`。
3. 接入 L-01 的 `lili/suli`，迁移旧状态名，保持任务不能直写掌握。
4. 为其余八字接入发现与调谐，按本阶段状态上限逐步增加主动证据。
5. 将 reducer 的状态提交接入章节里程碑与试玩埋点。

## 10. 验收

- P0 恰好十二个唯一词，关键发现全部可恢复。
- 十二字全部有读音、两个对照语境和至少一个窄义误解修复项。
- 状态单调且幂等；相同事件、相同变体、重置和读档不能重复奖励。
- 工具旁路、H2/H3、答案可见、固定槽位和仅颜色提示不能产生 `produced/stabilized` 证据。
- `produced` 至少两个任务家族，并冻结其环境指纹基线；`stabilized` 需要新家族、新环境的两份迁移证据、彼此不同的指纹/变体、逻辑延迟与两个语义面。
- 试玩目标：90% 玩家三小时内发现至少八字；发现中位 10–12、奠义 5–8、产出 4–6；延迟识别率 80%；至少 60% 玩家能无强提示主动用四字。
- 正式冻结前至少两名 toki pona 社群审阅者检查语义、例句与“施法记法不等于完整自然句”的提示。

## 11. 已知未知

- 同时发现 10–12 字而只主动产出四字，是否仍会造成“收集很多、会用很少”的挫败感。
- 两个任务家族是否足以证明产出，第三个迁移任务是否会显得重复。
- 通用刻印媒介应完全免费，还是由安全的非语言劳动稳定供给。
- H1 提示在不同书写背景与可访问性模式下应显示多少信息。

这些问题进入试玩，不通过增加机械重复次数提前伪装成已知答案。
