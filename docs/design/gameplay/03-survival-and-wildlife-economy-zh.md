# G-03 补充规格｜软生存需求与动物素材经济

状态：系统规格 v0.1<br>
适用：连续存档的慢节奏 RPG；第一章序章及后续地区<br>
机器数据：[`survival-needs.v0.1.yaml`](../../../data/player/survival-needs.v0.1.yaml) · [`wildlife-products.v0.1.yaml`](../../../data/economy/wildlife-products.v0.1.yaml) · [`cross-save-wal.v0.1.yaml`](../../../data/persistence/cross-save-wal.v0.1.yaml)

## 1. 设计结论

游戏增加独立的饱食度与口渴度，范围均为 `0–100`。它们用于形成旅行、饮食、营地、聚落和加工经济的节律，不是持续催促玩家的倒计时，也不能影响道本语解析、表达容量、MP、语言证据或法术伤害。

普通动物允许被杀死。死亡不会直接爆出金币或散落肉皮，而是生成一具可搬运、会腐败且只能结算一次的尸体。玩家使用刀具或聚落屠宰台取得肉、皮，再烹饪、风干或鞣制，最后自用或卖给对应商人。

和平主线保持不变：前三小时必需击杀数仍为 0，食物存在植物、购买、公共餐和援助路线，皮革存在旧皮回收、布料和购买替代。动物素材不会成为路线钥匙、攻击资格、语言成长或唯一装备升级来源。

## 2. 饱食与口渴

### 2.1 衰减

| 状态 | 初始值 | 每活跃探索小时 | 三小时无补充后的基线 |
|---|---:|---:|---:|
| 饱食度 | 85 | −6 | 67 |
| 口渴度 | 90 | −10 | 60 |

系统持久化两条单调时钟：主动世界时钟驱动物理、腐败和加工；代谢时钟只在非豁免的世界活动中推进。聚落加工会增加前者而不增加后者，因此能记录工时且不消耗饱食/口渴；暂停、对话、冥想、组词、离线和 L-01 同样不推进代谢。奔跑、连续挖掘或炎热环境最高只将序章消耗提高到 `×1.25`。

### 2.2 阈值

| 数值 | 反馈与影响 |
|---:|---|
| 60–100 | 正常；不提供“必须吃满”的增益 |
| 35–59 | 柔和提醒；不减属性 |
| 20–34 | 体力恢复 −10%，自然 HP 恢复 −25% |
| 1–19 | 体力上限 −15%，自然 HP 恢复暂停 |
| 0 | 不掉血、不死亡；体力恢复 −30%，移动速度仍至少为正常的 90% |

两条需求影响同一属性时取较差倍率而不相乘；体力恢复最大惩罚 30%，移动最大惩罚 10%。序章返回观察提交前，两项数值最低锁在 20；`prologue_survival_floor_released` 结算并持久化后下限永久解除。

### 2.3 恢复来源

- 清水：口渴 `+35`；初始水壶有 3 次饮用，每次 `+25`；
- 即时饮用显化的 `telo`：口渴 `+20`，但不能装瓶、出售、永久储存或生成语言证据；
- 旅行口粮：饱食 `+30`；
- 熟肉：饱食 `+35`；
- 根茎炖食：饱食 `+50`、口渴 `+10`；
- 序章中的生肉不能直接食用，先不引入随机疾病系统。

## 3. 前三小时教学

| 内容预算 | 安排 |
|---|---|
| 0–25 分钟 | 隐藏并冻结需求条，只让玩家理解溪流、材料和 `telo` |
| 25–50 分钟 | 聚落共享水井与公共植物餐演示一次；可跳过，不答题，使用后两条至少为 90 |
| 50–110 分钟 | 水井、携带水或即时 `telo` 均可解渴，不要求施法 |
| 110–150 分钟 | L-01 全程冻结需求，不能打断 21 MP 的长度对照 |
| 140–165 分钟 | NPC 可示范处理购买、赠送或自然死亡来源的尸体，不要求玩家杀狐狸或兔子 |

前三小时不增加主动新词；`moku` 最多作为可忽略的接受性曝光。后续可按每段最多两个主动词依次引入 `moku/kili`、`soweli/selo`、`seli/lete`、`esun/mani`。`moku soweli`、`selo soweli` 等只是语境表达，不是唯一标准译名。

## 4. 动物产物与生态后果

| 动物 | 成年个体完整处理产物 | 生态变化 |
|---|---|---|
| 兔子 | 小型鲜肉 ×2、小皮 ×1 | 狐狸觅食压力上升，草地啃食下降 |
| 狐狸 | 低价食肉动物肉 ×1、中型毛皮 ×1 | 兔子增多，聚落菜地损害压力上升 |
| 蝙蝠 | 小型鲜肉 ×1，无可用皮 | 飞虫增加；失去活体振动预警，但裂纹、落尘和石响仍保留 |
| 泥蛙 | 小型鲜肉 ×1，无可用皮 | 湿地昆虫和环境声发生变化 |

幼兽没有可采集产物。动物不会在检查点或读档后立刻刷新；新个体只有在栖息地仍然有效并经过多个无关世界事件后才可能补充。过量狩猎通过真实种群、捕食关系、环境声音和聚落物资变化反馈，不使用抽象善恶值。

武器、火焰、爆炸和重物会影响尸体完整度：干净刀具保持完整产量，无工具无法取得完整皮，燃烧或爆炸会显著降低皮的品质。不存在随机稀有皮或因残酷方式获得的额外奖励。

## 5. 两步加工链

```text
动物死亡
→ 唯一尸体记录
→ 刀具／屠宰台：鲜肉＋生皮
→ 厨房：熟肉，或风干架：肉干
→ 制革坊：熟皮革
```

从尸体到肉或皮算第一步；烹饪、风干或鞣制算第二步。加工不使用现实时间等待：风干由两个无关世界事件推进，鞣制由一个无关世界事件推进。玩家可以继续探索，回来领取。

显化热量可以作为烹饪能量，因为它没有创造可售物质；显化肉、显化皮或把显化物混入天然物后洗成可售商品都被禁止。腐败肉也不能通过烹饪刷新成新鲜肉。

## 6. 聚落市场

- 屠夫收购生肉、熟肉和肉干；每个补货周期前 2 份按正常价，其余按四分之一价格或拒收；
- 序章制革者只收购完成鞣制的皮革，不直接收生皮；每周期前 1 张按正常价，其余降价或拒收；
- 生肉约 1 金币、熟肉约 2；熟小皮约 2、中型熟皮约 3，兔子完整加工后的售出总额也不超过 6；
- 一只小型动物完整加工后的净收益不超过 6 金币；
- 维修、运输、测绘等非暴力工作基准为每 10 活跃分钟约 10 金币，狩猎收益效率不得超过其 60%；
- 商人不会在序章发布必须狩猎的任务，也不显示击杀进度。

报价冻结商人需求版本、批次所有权/新鲜度版本和单价，读档后旧报价失效且只能消费一次。补货必须经过 3 个互不相同且不可重放的合格世界事件；读档、检查点重置、往返场景和重复同一事件都不能刷新全价额度。

这让狩猎成为玩家愿意承担搜索、加工、腐败和生态代价时的一种副收入，而不是最优刷钱路线。

## 7. 存档与防复制

每次动物出生都有新的 `life_instance_id`。死亡事务以 `(region_save_id, life_instance_id)` 为唯一键，`corpse_id = sha256(economy_id, life_instance_id)`；数据库再对 `life_instance_id` 建唯一约束，因此并发死亡或重放也只能生成一具尸体。

尸体内部保存肉、皮等资源槽。采集采用版本比较并交换，所有 lot 和 receipt ID 均由事务 ID 确定性派生。加工拆成 `start → complete → claim` 三个事务；完成前在腐败结算后重验原料，变质则进入 `failed_spoiled` 且不产出，玩家可取消并取回；完成品先归工位保管，再由领取事务转给玩家。

这些操作横跨地区尸体、全局库存、工单、钱包和商人账本，因此统一由跨存档 WAL 协调：prepare 记录完整 redo envelope 并让所有参与存档取得持久锁/预约，全部确认后才允许 commit，随后按 envelope 向前重放。场景激活前必须完成固定点恢复；已提交的死亡、进食、采集、加工子事务、种群补充和售卖均不会被阶段重置撤销。

## 8. 验收标准

- 序章因饱食或口渴死亡、卡关或被迫狩猎次数均为 0；
- 生存 UI 占主动游玩时间不超过 3%，需求打断语言交互的比例低于 2%；
- 开启需求系统后，H0/H1 主动取回成功率相对关闭组下降不超过 5 个百分点；
- 任一必经点的基础食水恢复路径在 P95 60 秒内可发现；
- 动物收益 P90 每分钟不超过非暴力工作收益的 60%；
- 击杀、加工和售卖产生的语言成长、EC、MP、攻击资格和任务钥匙事件均为 0；
- 重置、重放或崩溃恢复产生的重复尸体、肉、皮、工单、金币和凭据均为 0；
- 若超过 10% 的测试玩家认为狩猎是最佳赚钱或成长路线，本轮经济验收失败。
