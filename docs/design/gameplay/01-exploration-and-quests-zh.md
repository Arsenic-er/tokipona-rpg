# G-01｜探索与任务

状态：初稿 v0.6  
依赖：跨文档契约 v0.1、世界规则集 v0.1  
范围：第一章纵向切片，以及后续地区可复用的任务模板

## 1. 文档职责

本文定义玩家在地图上做什么：发现、移动、交战、观察、表达、修复误解、改变环境、推进人物关系并回访旧区域。

本文不定义语法规则、解析算法、对象状态转换和世界物理。任务必须通过 `rule_id` 调用《W-01｜世界规则》，不能为推动剧情添加隐藏例外。

## 2. 设计目标

1. 语言进入“观察—意图—行动”链条，而不是战斗前插入一道题。
2. 新词先在可理解情境中出现，再由玩家主动检索和组合。
3. 同一语言知识必须在战斗、环境、沟通等不同情境复用。
4. 核心任务允许战斗、环境操作、沟通或重述等多种解决路径。
5. 完成任务应留下可见且持久的世界变化：水路、捷径、NPC、生态或聚落设施。
6. 失败应柔性且可修复；死亡、读档和语言失误不清除已学内容。
7. 新手可借助分层提示完成，但纯图标不能成为永久绕开语言的最优策略。

## 3. 核心循环

### 3.1 局部循环

```text
发现异常
→ 观察对象、人物需求与环境线索
→ 形成意图并选择词/结构
→ 探索、战斗或施法
→ 世界给出可见后果
→ 确认、澄清或重述
→ 任务状态和局部世界改变
```

### 3.2 地区循环

```text
进入地区
→ 建立安全点和主路径
→ 接触人物任务与区域冲突
→ 获得新的语义/句法/行动能力
→ 解决区域核心问题
→ 解锁捷径、设施或下一地区
→ 带着新能力回访旧地点
```

### 3.3 长期成长

- 地图成长：路径、捷径、安全点与环境状态永久变化。
- 人物成长：信任、职责和对玩家表达习惯的反馈发生变化。
- 语言成长：从识别到引导输出，再到独立迁移与延迟检索。
- 法术成长：扩大可表达的意图、控制精度和组合空间；不直接增加“答题伤害倍率”。

## 4. 地图与探索结构

### 4.1 每个地区的标准构成

- 一个安全入口或聚落据点；
- 一条清楚的首次主路径；
- 两至三条可选支路；
- 一条由任务或能力开启的永久捷径；
- 一个需要新语言/行动能力回访的旧地点；
- 一个把语言概念物质化的环境主题；
- 一个能通过多种方式处理的区域冲突。

地区不是独立“单局”。玩家可随时返回已开启的地点；死亡从最近安全点恢复，任务与语言证据不回滚，关键环境状态按明确检查点规则保存。

### 4.2 门槛类型

| 门槛 | 示例 | 设计要求 |
|---|---|---|
| 行动门槛 | 需要精确移动、升温、降温或推动 | 不能只检查某个词是否解锁 |
| 环境门槛 | 水位、温度、泥层、气流改变后可通行 | 状态变化需可观察、可预测 |
| 社会门槛 | NPC 需要理解玩家的意图或承诺 | 至少接受两种合理表达/修复路径 |
| 世界状态门槛 | 先修水路、救出人物或停止装置 | 由目标谓词判断，不由剧情按钮直改 |

禁止“输入唯一标准句才能开门”。玩家必须理解门后的意图或环境关系，而不是猜作者字符串。

### 4.3 回访价值

每个主地区至少安排一次回访，触发因素可为：

- 新的移动或法器能力；
- 对旧词更宽语义范围的理解；
- NPC 因世界变化给出新需求；
- 未见过的迁移任务，以验证真正学习而非记住关卡答案。

## 5. 任务类型

| 类型 | 主要体验 | 语言证据 |
|---|---|---|
| 主线任务 | 改变地区核心状态 | 综合理解、独立表达、迁移 |
| 人物支线 | 理解需求、承诺、解释差异 | 意义协商与修复 |
| 探索任务 | 发现地点、记录现象、建立路径 | 观察描述与语境推断 |
| 研究/冥想 | 回忆、分类、改述、比较多个表达 | 检索、间隔与元语言反思 |
| 环境修复 | 改变水、热、泥、石、气流 | 词义多面性与因果表达 |
| 战斗/Boss | 在压力下准确控制作用对象和范围 | 自动化检索与组合，不以语言正确率换伤害 |

## 6. 任务状态机

```text
Locked → Available → Active ↔ Suspended
                         ↓
                 ResolutionPending
                         ↓
                    Completed → Archived

Active → Abandoned → Available
```

单项目标状态：

```text
Pending → Active → Succeeded
                    ↘ SoftFailed → Active
                    ↘ Skipped
```

约束：

- 死亡和读档不自动改变任务状态。
- 当前版本不设置隐藏计时器；若未来存在叙事期限，必须公开并提供替代结果。
- 世界状态结算必须是原子操作，避免奖励、NPC 和环境只更新一部分。
- NPC 死亡、移动或敌对不得造成不可恢复的主线软锁。
- 所有柔性失败都必须给出稳定 `feedback_code` 和继续路径。

## 7. 语言学习编排

每个核心知识点必须完成以下序列：

1. 可理解输入：玩家从行动、画面、声音和少量文本推断含义。
2. 注意形式：系统突出此次理解依赖的词、粒子或语序。
3. 引导使用：玩家在受限但非唯一答案的情境中表达。
4. 独立产出：撤除部分提示，在新目标上再次使用。
5. 世界反馈：结果由对象变化、人物反应和空间关系呈现。
6. 修复：歧义或误解后，玩家可澄清、换词或拆成两句。
7. 未见迁移：在不同对象、地点或任务类型中应用。
8. 延迟检索：一段游戏进程后，由冥想或回访再次调用。

每个首章内容词至少出现三个有意义的情境；每个首章结构至少包含一次输入、一次引导输出和一次独立迁移。

### 7.1 反馈四轴

- 形式：当前语言配置能否解析。
- 语境：表达能否指向此刻的对象、关系或动作。
- 交际充分性：是否足以让人物或系统理解玩家意图。
- 任务结果：世界状态是否满足目标谓词。

四者不得压缩成“对/错”。合法歧义不是语言错误，任务成功也不等于已经掌握。

### 7.2 分层提示

1. 重放环境线索；
2. 提示意图类别，不给完整句；
3. 提示可能相关的词或粒子；
4. 展示两个可比较的部分表达；
5. 给出完整示例并要求玩家在新对象上改写。

提示随成功逐步淡出。改变目标、材料、位置和人物需求，防止玩家靠固定手势或图标刷过任务。

## 8. 第一章纵向切片

### 8.1 地区：溪谷聚落与渗水矿窟

地图构成：

- 溪谷聚落：安全点、人物关系和冥想据点；
- 旧水道与河岸：水轮、闸门、结冰/加热实验；
- 渗水矿窟：主地下区、泥层、裂隙和气流；
- 泵房、潮湿仓库、矿工营地：支线与多路径任务；
- 深层构装体：可战斗，也可通过修复环境令其停止；
- 章节结束后：水路、供水、矿道捷径和 NPC 分布产生永久变化。

### 8.2 首章语言范围

候选内容词：

```text
telo seli lete kiwen ko kon
tawa kama pona pakala awen wawa suli lili
```

首章结构冻结为：`o`、`li`、`e`。

首章重点是一词共鸣、二词尺度/状态塑形、三词安全动作关系，以及四词以上的精调命令/主谓宾表达。`la`、条件施法、时间触发、`pi` 和复杂并列从后续章节开始正式教学；熟练玩家提前输入可解析的 `la` 表达时，系统说明“超出本章教学范围”，不能判为错误道本语。

### 8.4 首章施法解锁节奏

1. **默认一词显化**：先用 `telo` 补水、灭火和压住机关，观察“不添加尺度修饰词”时生成 2 格默认水段，并在释放后受重力下坠。这里的“默认”只是游戏构形，不是 toki pona 中的“标准长度”。
2. **较短形态｜`lili`**：在近距离、低顶棚和精密落点任务中使用 `telo lili`；固定截面不变，只有轴向长度变成 1 格。
3. **再次主动省略**：给出恰好适合 2 格水段的任务，让玩家主动选择 `telo` 而不是把“默认”误记成第三个长度词；记录 `default_is_unspecified` 证据。
4. **较长形态｜`suli`**：在高位蓄水槽或跨隙导流中使用 `telo suli`；固定截面不变，轴向长度变成 4 格。
5. **跨元素长度迁移**：把较短、默认、较长三种形态迁移到 `seli/kiwen/ko/kon` 的未见场景；三档都必须各有独特优势，界面不得呈现为弱/中/强。
6. **二词状态塑形**：用 `telo kon` 悬浮并搬运水球；维持取消或 MP 耗尽时，水恢复普通重力。
7. **二词非攻击运动**：用 `telo tawa` 形成低速水流，完成浇灌、输水和推动轻物。
8. **三词安全动作**：用 `telo o tawa` 沿公开焦点低速搬运水。表达已成立，但能量、速度和活体作用都被限制在实用档，不是直接攻击。
9. **首个直接攻击结果**：到章节约 70% 时，才开放至少四个有效词且命中获准攻击签名的表达，例如稳定移动水球 `telo kon o tawa`、受控运动的长水柱 `telo suli o tawa` 或有力移动 `telo o tawa wawa`。攻击资格来自完整语义角色与 MP 报价；伤害来自随后的碰撞、温度和材料状态，不来自第四个词本身。
10. **综合迁移**：首领同时要求显化、长度选择、悬浮、输送与定向运动，不能只重复一个攻击表达。

四词只是本作直接攻击的**必要条件**，不是道本语的一般句长规则，也不是充分条件。重复词、无关填充或缺少动作/能量关系的四词表达不会变成攻击；少于四词的有效表达也不能被标成语法错误。

### 8.5 慢节奏与攻击解锁证据

“慢”来自概念逐层增加、世界准备和跨情境迁移，不来自现实时间锁或重复刷题。首个攻击签名解锁前必须收集不同类别的学习证据：

- 玩家必须分别提交一次无提示的“较短形态｜`lili`”“默认形态｜不添加尺度修饰词”“较长形态｜`suli`”；默认选择单独记录 `default_is_unspecified`，不能把它当作隐含词；
- 较短、默认、较长三类各至少覆盖三种任务家族；同一任务变体最多提供一次主要证据，三类都要出现“该形态独有优势”而非弱/中/强排序；
- 长度组合至少跨两种材料迁移，其中一次为未见组合结果预测；至少两次成功之间插入无关探索内容，再进行延迟迁移；
- `N o tawa` 在三个目标不同的非战斗任务中使用；`wawa` 如进入首个攻击表达，须先驱动一次非战斗机关；
- 至少完成一次误解后的改述，以及一次被其他探索内容隔开的延迟回忆；
- 完成法器四槽稳定试炼和安全靶场迁移。

完全相同的提示、对象、场景和答案只能提供一次主要解锁证据；击杀数不计语言熟练证据。流程不设置现实时间倒计时、签到、体力等待或强制重复关卡。已经掌握道本语的玩家可通过含未见组合的无提示挑战跳级。攻击解锁前的威胁必须保留躲避、近战、工具和环境解法。

## 10. 验收标准

### 章节体验

- [ ] 玩家能连续完成第一章，无单局重开或限时清档。
- [ ] 至少两次可选路径、一次永久捷径和一次有意义的回访。
- [ ] 死亡/检查点恢复不清除任务与语言证据。
- [ ] 存档重载后任务、NPC、环境和捷径状态一致。
- [ ] 主线不因 NPC 状态、支线顺序或柔性失败而软锁。
- [ ] 至少一次永久世界改变在章节结束后仍可观察。

### 玩法与语言

- [ ] 每个核心任务至少有两个方法类别或两个合理表达路径。
- [ ] 成功由目标谓词判断，不由答案字符串判断。
- [ ] 每个内容词至少出现在三个不同情境。
- [ ] 每个结构都有输入、引导输出和独立迁移。
- [ ] 至少有一次歧义修复和一次延迟未见迁移。
- [ ] 图标、攻击按钮或背板不能永久绕开表达。
- [ ] 反馈能区分形式、语境、交际充分性和任务结果。
- [ ] 原始自由文本默认不上传。
- [ ] 玩家能解释 `telo` 的下坠来自重力，而不是词义。
- [ ] 玩家能区分 `telo kon` 的开放语言意义与本作悬浮惯例。
- [ ] 四词攻击签名解锁前的必做战斗均有近战、躲避、工具或环境解决路径。
- [ ] 首次攻击前包含 suli/lili 长短对照、三次不同目标的非战斗动作、一次改述和一次未见迁移。
- [ ] 相同场景的机械重复不能无限推进攻击解锁；熟练玩家可以通过未见组合测试跳级。
- [ ] 首章所有必做任务均可在不使用 `la` 的情况下完成。

## 11. 已知未知

- 地区尺寸、移动速度、战斗与语言交互的时间比例。
- 14 个词是否足以支撑十二个任务而不显重复，尤其是单长度轴跨材料迁移的内容成本。
- 首个四词攻击签名放在章节约 70% 是否合适，以及不同玩家完成证据集合所需的实际游玩时长。
- 每个意图应接受多少表达，内容制作和审校成本才可控。
- 提示淡出速度和新手挫败阈值。
- 玩家是否会用捷径跳过必要迁移，而不是把捷径视为成长奖励。
- 检查点应保存到多细的环境粒度。
- 两条水路的永久差异应多大，才有意义但不产生内容爆炸。
- 中文、英文和其他母语玩家对解释需求的差异。
- 道本语社群审校者的持续容量和版本争议处理方式。

- roguelike、程序生成主世界、单局构筑和死亡清档；
- 全量自然语言理解、由 LLM 最终判定表达；
- ASR 语音识别、多人同步战斗、玩家经济；
- 通用 UGC、公共排行榜和惩罚式 streak；
