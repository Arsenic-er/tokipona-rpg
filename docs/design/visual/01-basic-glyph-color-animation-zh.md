# V-01｜首批 14 个单字咒语：字形颜色与激活动画

状态：视觉原型 v0.1（待用户与社群审阅）  
数据依赖：`chapter-01.4`、`magic-glyph-visuals.v0.1`  
范围：完整 `pu-120` 中首批 14 个单字施法原型的 sitelen pona 显示，不代表全部基础词；完整目录见 [V-02｜pu-120 字形、魔法域与激活目录](02-pu120-glyph-catalog-zh.md)

## 1. 设计结论

字形、颜色、动画和承载背景是四个独立变化轴：

1. **字形层**：使用精确 sitelen pona 遮罩；存档身份始终是拉丁 `wordId`。
2. **颜色层**：单字具有本作内部的魔法类别色；操作词进入组合后可继承其实际作用对象的颜色。
3. **动画层**：8 帧整字同步变亮；所有帧使用同一 Alpha 遮罩，不沿笔画传播。
4. **背景层**：石、木、泥土、金属只影响凹槽、切削边、遮挡和反光，不进入字形图集。

颜色只表达本作的魔法亲和或执行角色，不声称是 toki pona 词义本身。不得给 `tawa` 固定箭头、给 `pona` 固定爱心或治疗十字、给 `pakala` 固定骷髅等会收窄语义的附加图标。

## 4. 组合时的颜色继承

单字审阅图使用固有色。咒语被编译成 `CastPlan` 后：

- `telo/seli/lete/kiwen/ko/kon` 保留固有类别色；
- `tawa` 继承被移动主体；
- `kama` 优先继承目标状态，其次继承变化主体；
- `pona/pakala/awen` 继承合法受作用对象；
- `wawa` 继承被增强效果；
- `suli/lili` 继承可延展中心词；
- 未解析出绑定对象时使用固有功能色，不猜测；
- 语法词使用中性银灰，不提供物质或能量色。

继承只替换三种颜色端点，角色纹理保持原词自己的样式。例如 `telo suli o tawa` 中，`telo/suli/tawa` 都可呈水色，但三者仍由波纹、长划和斜向节拍区分。

## 5. 八帧动画合同

| 帧 | 激活码 | 语义 |
|---:|---:|---|
| 0 | 32 | 未激活，完整但低亮 |
| 1 | 48 | 初始响应 |
| 2 | 72 | 弱共鸣 |
| 3 | 96 | 中间态一 |
| 4 | 128 | 中间态二 |
| 5 | 164 | 稳定成形 |
| 6 | 208 | 接近激活 |
| 7 | 255 | 已激活并保持 |

硬性约束：

- 每格 `32×32 px`，实际字形限制在 `24×24 px` 内；
- 八帧 Alpha 遮罩逐像素完全相同；
- 禁止旋转、逐帧裁切、缩放、笔画传播和亚像素插值；
- 运行时图集保存统一灰度激活码，颜色由调色板查询；
- 角色纹理使用独立遮罩，裁剪在核心字形内部；
- 彩色逐帧条和 GIF 只是审阅输出，不是运行时真源。

## 6. 背景材质接口

运行时合成顺序：

```text
绘制石／木／泥／金属背景
→ 从字形遮罩派生当前材质的槽影与切削边
→ 应用八帧亮度和当前调色板
→ 应用角色纹理／可访问性增强
→ 与当前可破坏实体材质遮罩求交
```

最终可见区域为：

```text
visibleGlyphMask = glyphInkMask ∩ currentSolidMaterialMask
```

背景被破坏时对应字形像素随之消失；字形不能悬浮在空气中。更换背景只替换 `surfaceProfile`，不得复制字形动画或彩色 atlas。

## 7. 当前未决项

- `lete/ko/kama/pona/pakala/wawa` 在首章何时被发现尚未编排；
- 角色纹理在 32px 字形上的覆盖率与色觉模拟仍需人工审阅；
- 木材和泥土的槽影半径、切削边方向与发光反射需要进入材质实验室验证；
- 14 个咒语的视觉原型不能替代语言社群审查和玩法生命周期审批；
- 本轮先冻结字形形状、颜色端点和八帧整体变亮，不冻结最终激活时长。
