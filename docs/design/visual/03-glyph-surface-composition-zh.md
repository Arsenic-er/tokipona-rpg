## 1. 目标与边界

本规范用于约束 sitelen pona 魔法字形在可破坏像素世界中的显示方式。核心原则是：**字形动画与承载它的背景材质必须严格分离**。

- 字形资源只负责字形形状、八帧亮度阶段和所属视觉颜色组；
- 石、木、泥、金属等表面只负责材质颜色、颗粒、刻痕、破坏和遮挡；
- 运行时再将两类资源合成，不为每一个“字形 × 材质”组合绘制独立动画；
- 所有合成均在整数像素坐标上进行，并使用最近邻采样；
- 本轮以 1 px 世界像素作为最小材质单位，不使用可见的大方格或平滑笔刷；
- 字形不会因为更换墙体、地板、器物或遗迹材质而改变标准轮廓。

本规范不决定单词的完整语义、咒语语法、解锁条件或激活消耗；这些内容应由语言、玩法和数值文档分别定义。

## 2. 分层数据模型

每个可显示的字形至少需要下列相互独立的数据层：

| 数据层 | 职责 | 是否随八帧动画变化 |
| --- | --- | --- |
| `glyphInkMask` | 字形的二值墨迹/发光区域 | 否 |
| `glyphFrameIntensity` | 当前帧的整体亮度 | 是 |
| `visualDomainPalette` | 十类视觉颜色组中的颜色 | 否 |
| `materialPixels` | 石、木、泥、金属的表面像素 | 否 |
| `inscriptionSupportMask` | 原始刻写依附关系；记录哪些材质像素真正承载刻痕 | 通常否 |
| `currentSolidMaterialMask` | 当前仍存在、可见且能承载字形的实体材质 | 会随破坏和物理状态变化 |
| `foregroundOcclusionMask` | 覆盖在字形前方的泥、灰、积水或其他遮挡物 | 会随环境变化 |

字形实际可见区域必须由两个承载蒙版共同限制：

```text
visibleGlyphMask = glyphInkMask
                 ∩ inscriptionSupportMask
                 ∩ currentSolidMaterialMask
```

随后才应用当前帧亮度、视觉颜色和前景遮挡。`inscriptionSupportMask` 与 `currentSolidMaterialMask` 不得合并成一个字段：前者表达“这个像素原本有没有字”，后者表达“这个像素现在还在不在”。二者分开后，墙体被挖掉再用新泥土填回时，新泥土不会错误继承旧字形。

推荐的运行时合成顺序如下：

1. 读取 `currentSolidMaterialMask`，生成当前材质表面；
2. 仅在 `inscriptionSupportMask` 支持的位置绘制刻槽阴影与 1 px 切边；
3. 用上式得到 `visibleGlyphMask`；
4. 将当前帧的整体亮度与视觉颜色应用到 `visibleGlyphMask`；
5. 如材质允许，仅添加受限的 1 px 邻接反光；
6. 最后应用 `foregroundOcclusionMask`。

不得使用模糊、双线性插值或扩大字形轮廓的柔光来补偿可读性。

## 3. 四类首发背景材质

四种材质都应使用细粒度的 1 px 像素结构。局部纹理可形成约 2–6 px 的自然团簇，但不得显露固定的 8×8、16×16 或更大贴图网格。

### 3.1 石质表面

- 以暗灰、炭黑、低饱和棕灰为主；
- 岩粒、裂纹和矿物杂点使用 1 px 硬边；
- 字形刻槽应有明确的 1 px 深色阴影和间断的亮侧切边；
- 破坏时按岩石像素簇剥落，字形随承载像素一起缺失；
- 不应将整块岩壁绘制成规则砖格。

### 3.2 木质表面

- 以暗棕、赭棕和少量暖色高光为主；
- 木纹沿局部生长方向延伸，但仍由离散像素构成；
- 刻槽阴影和切边应呈破碎、纤维化的 1 px 线段；
- 燃烧、劈裂或腐朽后，承载像素消失的部分不得继续显示字形；
- 新装上的木板不自动继承旧刻写记录。

### 3.3 泥土表面

- 以深褐、湿土灰、低饱和黄褐为主；
- 纹理应表现湿度、颗粒和局部压实差异，避免棋盘状噪点；
- 刻槽对比度应低于石材，边缘可间断，但必须满足最低可读性门槛；
- 流动或覆盖过来的泥可以通过 `foregroundOcclusionMask` 暂时遮挡旧字形，而不一定删除 `inscriptionSupportMask`；
- 泥被清除后，若原承载像素仍在，旧字形可以重新显露；若原承载像素已被挖除，则回填泥土不得恢复旧字形。

### 3.4 金属表面

- 以冷黑、蓝灰、铁灰和少量高亮金属像素为主；
- 使用短促、方向一致的 1 px 划痕或氧化斑，不使用平滑渐变；
- 刻槽应具备四种材质中最清晰的 1 px 暗边与亮边；
- 金属弯曲或位移只能做整数像素重映射，不得用双线性缩放扭曲字形；
- 金属熔毁、断裂或被切除后，失去承载的字形像素必须同步消失。

## 4. 八帧整体渐亮动画

每个单字的激活动画统一使用八帧，表现“从未激活到完全激活”的整体逐渐变亮。八帧之间只允许改变亮度分配；不得改变字形位置、轮廓、透明区域、颜色类别或局部纹理。

建议语义阶段如下：

| 帧 | 视觉状态 | 设计意图 |
| --- | --- | --- |
| 1 | 未激活 | 主要依靠刻痕与极暗字形辨认 |
| 2 | 微弱响应 | 整体略微提亮，不出现局部先行点亮 |
| 3 | 能量汇入 | 全字同步增强 |
| 4 | 可识别中间态 | 字形主体达到稳定可读水平 |
| 5 | 激活过半 | 颜色更加明确，但不出现轮廓膨胀 |
| 6 | 接近激活 | 整体亮度继续提高 |
| 7 | 临界状态 | 接近最终高亮，保留材质关系 |
| 8 | 完全激活 | 最高亮度与清晰边缘，不使用柔光糊边 |

播放时不得引入逐笔书写、从中心扩散或随机闪烁。若将来需要仪式性特效，应作为独立特效层添加，不得破坏这套标准八帧字形资源的二值轮廓与整体渐亮规律。

## 5. 十类颜色的职责

120 个单字可按十类视觉颜色组组织，以帮助玩家辨认、记忆和建立组合预期。颜色组只是一种游戏视觉导航，不是对 toki pona 词义的权威划分。

- 同一单词在上下文中可以承担不同角色；
- 颜色不得充当词义答案、词性答案或唯一施法效果答案；
- 界面应说明单字提示是游戏中的原型线索，而不是该词全部含义；
- 组合咒语的实际效果应依据上下文角色、词序和玩法规则决定；
- 对含义跨度较大的词，应提供两个以上互相对照的游戏语境，避免颜色将其固定成单一英语词义或单一词性；
- 性别、身体和亲密关系相关词不得依赖刻板的身体轮廓或颜色编码。

因此，十类颜色应在数据中命名为视觉域（例如 `visualDomainId`），而不应作为语义域的唯一真值来源。

## 6. 可破坏、遮挡与回填规则

### 6.1 销毁

当承载材质像素被挖掘、燃烧、熔化、震碎或爆炸移除时，对应位置必须从 `currentSolidMaterialMask` 中清除。该位置的字形、刻槽和反光应同时消失，不得悬浮在空洞中。

### 6.2 遮挡

灰尘、泥浆、苔藓、积雪或其他覆盖物可以只改变 `foregroundOcclusionMask`。遮挡不会自动删除原有 `inscriptionSupportMask`，所以覆盖物清除后，仍完整的刻字可以重新出现。

### 6.3 回填与替换

被挖空位置后来重新变为实体，只应恢复 `currentSolidMaterialMask`。如果新材质没有独立的刻写事件，`inscriptionSupportMask` 仍保持空缺，因此旧字形不会在新材质上重生。

```text
原字形被挖除 → support = 0, solid = 0, visible = 0
新材质回填   → support = 0, solid = 1, visible = 0
重新刻写     → support = 1, solid = 1, visible = glyphInkMask
```

若发生材质替换、机关搬运或整数像素变形，刻写支持关系必须由明确的游戏规则迁移，不能仅因为目标位置存在实体材质就自动复制。

## 7. 像素、对比度与可读性门槛

所有评审图与运行时合成都应满足以下门槛：

- 字形核心蒙版为二值蒙版，不包含半透明抗锯齿像素；
- 材质、刻槽、切边和字形均以整数像素对齐；
- 放大预览只允许整数倍最近邻缩放；
- 连续帧使用完全相同的字形轮廓和透明区域；
- 未激活刻痕相对相邻材质的对比度不低于 `1.8:1`；
- 第 4 帧字形主体相对局部材质中位亮度不低于 `3.0:1`；
- 第 8 帧字形主体相对局部材质中位亮度不低于 `4.5:1`；
- 第 8 帧字形主体相对最亮相邻材质像素不低于 `3.0:1`；
- 可访问性高对比模式的目标值不低于 `7.0:1`；
- 若某个表面未达标，应优先加深局部刻槽、压低字形下方材质或调整离散色阶，不应添加模糊外发光。

当前自动化门禁采用适合纹理像素背景的分布式硬阈值：

- 第 1 帧逐像素对比度中位数不低于 `1.25:1`；
- 第 8 帧逐像素对比度中位数不低于 `3.0:1`；
- 第 8 帧第 10 百分位不低于 `2.0:1`；
- 第 8 帧强调像素第 10 百分位不低于 `3.0:1`；
- 第 8 帧中位数相对第 1 帧至少增加 `1.5`；
- 相邻帧的线性 sRGB 亮度增量严格为正，且不得低于 `0.007`。

上面的自动门禁是最低线，前述 `1.8/3.0/4.5/3.0` 是人工视觉审阅目标。未来高对比模式的 `7.0:1` 尚未实现，因此不计入本轮像素通过结论。

这些数值是首轮视觉验收门槛，仍需在实际显示器、游戏缩放倍率、色觉差异与动态场景中复核。

## 9. 未决审阅项

- 四种表面在实际游戏镜头缩放下是否仍保持细粒度，而不会显得过密或过黑；
- 十类视觉颜色在四种背景上的辨识度、色觉无障碍和相互区分度；
- 八帧播放速度、停顿与循环策略，以及“完全激活”是否需要保持常亮；
- 低对比度泥土表面能否在不加入柔光的情况下稳定通过可读性门槛；
- 木材燃烧、泥土流动和金属变形时，`inscriptionSupportMask` 应在何种物理条件下迁移或永久失效；
- 字形跨越多个可独立破坏的材质粒子时，碎裂后的剩余片段是否仍可被玩家正确识别；
- 前景遮挡物应完全遮蔽字形，还是允许已激活字形以有限比例透出；
- 重新刻写所需的材料、法器、魔力与语言练习条件；
- 十类颜色组的名称、成员和代表字是否会误导玩家理解词义；
- 高对比模式应替换调色板、增加切边，还是同时提供形状辅助提示。
